## Context

Создание системы автономной оптимизации рекламы в Яндекс Директе для timber-frame-spb.ru.
Система использует PAI Algorithm v4.0-alpha с Autoresearch sub-loop для итеративной
оптимизации CPA через API, обходя алгоритмы Яндекса которые оптимизируют расход, а не
конверсии рекламодателя.

### Architecture
- PAI Algorithm = стратегический слой (цели, риски, обучение)
- Autoresearch sub-loop = тактический слой (ставки, минус-слова, A/B тесты)
- YandexDirect skill + API = исполнительный слой
- Verification scripts = измерение CPA/CTR/конверсий
- Guard scripts = бюджетная безопасность

### Risks
- Реклама ≠ ML: откат не возвращает деньги (нужны стоп-лоссы)
- 24-72ч цикл: каждый discard = дни, не минуты
- Нет данных без бюджета: chicken-and-egg
- Яндекс может заблокировать за "подозрительную автоматизацию"
- Сезонность: строительный сезон апрель-ноябрь (C1)
