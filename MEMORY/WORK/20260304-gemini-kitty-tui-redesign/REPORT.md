# Gemini CLI — Kitty TUI Redesign Report

## Summary
Проведена полная унификация и визуальная модернизация TUI-интерфейса дашборда PAI в Kitty Terminal с внедрением централизованной библиотеки компонентов и исправлением геометрии отрисовки.

## Files Changed
| File | Changes |
|------|---------|
| `config/kitty/scripts/lib/ui.sh` | **Новый файл.** Общая библиотека UI-компонентов, палитры и хелперов. |
| `config/kitty/scripts/command-center.sh` | Полный рефакторинг на базе `ui.sh`, внедрение динамических цветов табов и безмерцающего обновления. |
| `config/kitty/scripts/telos-dashboard.sh` | Переход с текстовых разделителей на боксовую структуру, унификация стилей. |
| `config/kitty/scripts/brigade-watch.sh` | Унификация заголовков и рамок, внедрение статусов Agent Zero в боксы. |
| `config/kitty/scripts/events-tail.sh` | Добавлен унифицированный боксовый заголовок. |
| `config/kitty/scripts/a0-chat-tail.sh` | Добавлен унифицированный боксовый заголовок. |
| `config/kitty/sessions/pai.session` | Исправлены статические echo-блоки (Tab 4-6) для соответствия ширине 96 символов. |

## What Was Fixed
1.  **Геометрия рамок:** Исправлена математика паддинга. Теперь ширина всех боксов ровно 96 символов (pixel-perfect).
2.  **Ошибка Printf:** Исправлен некорректный вывод паддинга (ранее выводились числа вместо пробелов).
3.  **Ширина Emoji:** Функция `vwidth` теперь корректно считает Emoji за 2 символа, предотвращая «съезжание» правого края рамки.
4.  **Мерцание (Flickering):** В `command-center.sh` команда `clear` заменена на Escape-последовательность `\033[H`, обеспечивая мгновенное обновление.
5.  **Визуальный шум:** Снижен контраст рамок (цвет `SEP`), что улучшило читаемость основного контента.

## What Was NOT Changed
- Логика получения данных (curl, jq, API вызовы Jules/A0).
- Цветовая палитра PAI (RGB значения сохранены).
- Горячие клавиши и интервалы обновления.

## UI Enhancements (New Features)
- **Shared Library:** Все скрипты зависят от `lib/ui.sh`, что позволяет менять стиль всей системы в одном месте.
- **Dynamic Tabs:** Вкладка "Center" меняет цвет (Зеленый/Желтый/Красный) в зависимости от результатов тестов и наличия хуков.
- **Semantic Badges:** Добавлены бейджи `ACTIVE`, `DONE`, `FAILED` с инвертированным фоном для статусов сессий.
- **Pulse Indicator:** Добавлен анимированный символ `●` в заголовке, подтверждающий активность скрипта.
- **Clickable Links:** Добавлена поддержка OSC 8 для создания ссылок в терминале.

## Known Limitations
- Функция `link` (OSC 8) требует поддержки со стороны терминала (в Kitty работает).
- Динамическая смена цвета таба требует настройки `allow_remote_control yes` в `kitty.conf`.
