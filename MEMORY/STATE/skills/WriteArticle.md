# WriteArticle — Workflow

> Создание экспертных статей для блога timber-frame-spb.ru.
> Каждая статья = SEO-оптимизированный экспертный контент с конкретикой.
> **ОБЯЗАТЕЛЬНО:** Сначала собрать Wordstat данные, потом писать.

---

## Входные данные

| Параметр | Обязательный | Описание |
|----------|-------------|----------|
| Тема/заголовок | ✅ | Заголовок или тема статьи |
| Целевая персона | ✅ | Андрей / Елена / Сергей |
| Длина (слов) | По умолчанию 1200 | 800-2000 слов |
| Ключевые слова | ❌ (собираем через Wordstat) | 3-5 целевых ключей для SEO |
| CTA | По умолчанию «Калькулятор» | Куда ведём читателя |
| Бриф | Опционально | Дополнительные инструкции из A0_TASK_BRIEF.md |

## Шаги выполнения

### ⚠️ Шаг 0: Wordstat Research (ОБЯЗАТЕЛЬНО)

**Ни одна статья не публикуется без Keyword Brief с реальными частотностями!**

1. Сформулировать 3-7 фраз-вариаций темы статьи
2. Запустить `Workflows/WordstatResearch.md` workflow
3. Получить Keyword Brief с частотностями из Yandex Wordstat
4. Определить Primary, Secondary, Supporting ключевые слова

```markdown
## Keyword Brief (пример)
| Фраза | Частотность | Приоритет |
|-------|-------------|-----------|
| терраса timber frame | 450 | Primary |
| фахверк терраса | 280 | Secondary |
| timber frame технология | 190 | Supporting |
```

**Пропуск этого шага = статья не принимается.**

### Шаг 1: Загрузка контекста
```
READ /a0/usr/skills/tf-content/TFExpertise.md
READ /a0/usr/skills/tf-content/TFBrandVoice.md
READ (Keyword Brief из Шага 0)
READ (бриф статьи, если указан)
```

### Шаг 2: Планирование структуры

Создать план статьи ПЕРЕД написанием:

```markdown
## План статьи
- **Тема:** [тема]
- **Персона:** [имя] — [что знает/не знает/боится]
- **Ключевые слова:** [из Keyword Brief, primary выделен]
- **Структура:**
  1. [H2: подтема] — [что раскрываем, ~X слов]
  2. [H2: подтема] — [что раскрываем, ~X слов]
  3. [H2: подтема] — [что раскрываем, ~X слов]
- **CTA:** [конкретное действие + ссылка]
- **Уникальный угол:** [чем статья отличается от конкурентных]
```

### Шаг 3: Написание

Правила при написании:
1. **Лид (первые 2-3 предложения):** Зацепка через боль или мечту персоны. Primary keyword в первом абзаце.
2. **Каждый H2:** Содержит хотя бы одну конкретную цифру (цена, размер, срок, характеристика).
3. **Таблицы:** Использовать для сравнений (наше vs обычное, материал A vs B).
4. **Внутренние ссылки:** Минимум 2-3 ссылки на другие страницы сайта.
5. **Финал:** CTA с конкретным действием, не абстрактный «свяжитесь с нами».

### Шаг 4: Самопроверка по Quality Gates

Пройтись по каждому гейту из SKILL.md:

```markdown
## Проверка
- [ ] Gate 0 Wordstat: Keyword Brief с реальными частотностями есть
- [ ] Gate 1 Brand Voice: нет запрещённых фраз, есть конкретика
- [ ] Gate 2 Technical: материалы/цены/нормы верны
- [ ] Gate 3 SEO: ключевые слова в H1/H2, meta description готов
- [ ] Gate 4 Persona: страхи адресованы, CTA для нужной стадии
```

### Шаг 5: Финальный пакет

Выдать статью в формате:

```markdown
---
title: "[SEO-заголовок]"
description: "[Meta description 150-160 chars]"
slug: "[url-slug]"
persona: "[Андрей|Елена|Сергей]"
keywords: ["ключ1", "ключ2", "ключ3"]  # Из Keyword Brief
wordstat_data:  # Реальные частотности
  ключ1: 450
  ключ2: 280
  ключ3: 190
cta: "[тип CTA]"
word_count: [число]
---

# [H1]

[Тело статьи...]
```

Сохранить в `docs/content/blog/[slug].md`

## Пример полного цикла

### Запрос: «Напиши статью про Timber Frame»

1. **Step 0:** Запускаю WordstatResearch с фразами:
   - "timber frame терраса"
   - "фахверк терраса цена"
   - "технология timber frame"
   - "каркасная терраса из бруса"
   
2. **Получаю Keyword Brief:**
   - timber frame терраса: 520 (Primary)
   - фахверк терраса: 340 (Secondary)
   - каркасная терраса: 890 (High volume, но конкурентная)
   - технология timber frame: 180 (Supporting)

3. **Step 1-5:** Пишу статью с этими данными

4. **Frontmatter включает wordstat_data** — доказательство data-driven подхода
