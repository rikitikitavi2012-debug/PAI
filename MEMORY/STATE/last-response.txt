## Что настроили сейчас?

Разделили на ДВА потока, которые живут параллельно:

### Поток 1: ПУБЛИЧНЫЙ (main) — для сообщества
```
Daniel (upstream) ←→ Наш форк (origin) ←→ Локальный main
```
- `main` — чистая копия кода Daniel, без наших данных
- Сюда мы отправляем PR-ы (баги, фичи) 
- Отсюда получаем обновления Daniel
- 3 PR-а уже открыты (#840, #808, #800)

### Поток 2: ПРИВАТНЫЙ (master) — наша версия Navi
```
Локальный master → private remote (PAI-personal)
```
- `master` — ВСЯ наша конфигурация, MEMORY, USER, хуки
- Бэкапится в приватный GitHub репо
- НИКОГДА не уходит в публичный origin
- Это и есть «наш компьютер», но с бэкапом в облаке

### Эти ветки НЕ связаны
У них нет общего предка (`merge-base` = пусто). Это две 
независимые истории в одном репо. Это нормально и правильно.

## Как не отставать от обновлений Daniel?

Одна команда:
  `git syncmain`   — скачает обновления Daniel, обновит main

А дальше ты ВЫБИРАЕШЬ что забрать в master:
  `git checkout master`
  `git checkout main -- PAI/Algorithm/v3.5.0.md`  (конкретный файл)
  Или: `git merge main` (всё, но аккуратно — будут конфликты)

Рекомендация: забирать ФАЙЛАМИ, не merge целиком. Потому что
Daniel обновляет CLAUDE.md, а у нас свой. Algorithm, Tools, 
Skills — это безопасно забирать.
