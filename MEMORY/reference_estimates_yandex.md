У Ivan на Яндекс почте хранятся PDF-сметы за 3 года работы прорабом по благоустройству. Высылала фирма.

**Ценность:** Анализ смет покажет реальные виды работ, объёмы, расценки, средний чек, сезонность. Это данные для TF Workbench (прайсы) и для позиционирования на сайте.

**How to apply:** Нужно вытянуть PDF из почты → положить в PAI → проанализировать. Шаги: (1) экспорт из Яндекс почты, (2) сохранить в DOMAINS/construction/estimates/, (3) парсинг и анализ.
