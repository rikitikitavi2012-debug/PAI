### Новые возможности

**Прокрутка**
- `pixel_scroll` — попиксельная прокрутка буфера истории (scrollback)
- `momentum_scroll` — инерционная прокрутка на Linux для тачпадов и сенсорных экранов
- Поддержка высокоточных событий прокрутки (high-resolution scroll) на X11 от тачпадов и аналогичных устройств

**Вкладки и окна**
- Перетаскивание вкладок мышью: можно менять порядок, перемещать между OS-окнами или отсоединять в отдельное окно (управляется через `tab_bar_drag_threshold`)
- Переименование вкладки двойным кликом по ней
- Изменение размеров сплит-окон мышью во всех лейаутах — параметр `window_drag_tolerance`
- Индивидуальные заголовки для каждого окна в сплите — параметр `window_title_bar`
- Новое действие для максимизации окна в сплит-лейауте (можно назначить на горячую клавишу)
- Видимый "след курсора" при переключении между вкладками; независимый цвет через `cursor_trail_color`

**Пользовательский интерфейс**
- Палитра команд (Command Palette) — открывается по Ctrl+Shift+F3; позволяет просматривать и запускать все действия, в том числе без назначенных горячих клавиш
- Shift+ЛКМ теперь расширяет текущее выделение, а не начинает новое (если мышь не захвачена приложением)
- Курсор-перекрестие при операции выделения прямоугольника — параметр `pointer_shape_when_dragging`

**Цвета**
- Поддержка цветовых пространств OKLCH и LAB при указании цветов в `kitty.conf`

**Клавиатура**
- Поддержка таймаутов для мульти-клавишных маппингов и режимов клавиатуры

**macOS**
- Поддержка Apple Dictation для ввода текста прямо в терминале
- Значок на иконке Dock при сигнале bell — `macos_dock_badge_on_bell`
- Новая комбинация Cmd+L для очистки последней команды и её вывода

**Wayland**
- Поддержка расширения для размытия фона (background blur)
- Режим `titlebar-only` в параметре `hide_window_decorations` — скрывает заголовок, сохраняя тени

**Remote Control**
- `goto_session` получил флаг `--active-only` для выбора только из активных сессий
- `remote_control_script` теперь разрешает относительные пути относительно директории конфига kitty
- `save_as_session` поддерживает `--base-dir` для указания базовой директории

**Shell Integration**
- Поддержка событий клика с Y-координатами относительно промптов

### Изменения в поведении (Breaking/Behavior Changes)

- **icat** отображает несколько изображений в порядке подачи на вход, а не в прежнем произвольном порядке
- **Ctrl+Shift+Delete** (сброс терминала) теперь также сбрасывает termios — это может затронуть скрипты, полагавшиеся на старое поведение
- Shell integration использует Y-координаты кликов относительно промптов (изменение логики событий)
