> Исследование: Standard Research (2 агента + WebFetch)
> Дата: 2026-03-12
> Контекст: Timber Frame Site — улучшение страницы /portfolio

## 1. Houzz Pro — структура портфолио

### Формат проектов на Houzz
- **Карточки в сетке** (3-4 колонки на десктопе, 1 на мобильном)
- Каждая карточка: hero-фото, название проекта, стиль/тип, локация
- Фильтры по: стилю, комнате, размеру, бюджету, локации
- Hover-эффект: overlay с краткой информацией

### Что показывают профессионалы на Houzz
- **До/После** — ключевой формат для ремонтов
- Множественные фото (10-30 на проект)
- Описание задачи клиента и решения
- Стоимость (диапазон)
- Используемые продукты (с ссылками)
- Отзывы клиентов прямо в проекте
- Награды (Best of Houzz)

### UX-паттерны Houzz
- Бесконечная прокрутка (infinite scroll)
- Lightbox-галерея с навигацией
- «Сохранить идею» (социальный букмаркинг)
- Рекомендации похожих проектов

## 2. ArchDaily — страница проекта

### Стандартная структура страницы проекта
1. **Hero-изображение** (полноширинное, высокого разрешения)
2. **Информационная карточка** (sidebar):
   - Архитектор / Бюро
   - Локация (город, страна)
   - Площадь (м²)
   - Год завершения
   - Фотографы
   - Материалы (перечень)
   - Категория проекта
3. **Описание проекта** — авторский текст (~500-1500 слов)
4. **Галерея фотографий** (15-40 изображений)
5. **Чертежи** — планы этажей, разрезы, фасады, детали
6. **Теги** (материалы, тип, стиль)
7. **Связанные проекты** — рекомендательный блок

### SEO-подход ArchDaily
- JSON-LD schema (Article + ImageGallery)
- Чистые URL: `/project-id/project-name-architect`
- Alt-тексты на всех изображениях
- Breadcrumbs (Главная > Проекты > Категория)
- Мета-описание с ключевыми данными (архитектор + локация + площадь)

### UX-паттерны ArchDaily
- Галерея с thumbnail-навигацией
- Sticky sidebar с данными проекта
- «Поделиться» и «Сохранить» кнопки
- Тёмный режим поддерживается
- Lazy loading изображений

## 3. Timber Frame компании — портфолио

### Bensonwood (bensonwood.com/portfolio/)

**Страница списка проектов:**
- Фильтры по категориям: Timber Frame, Mass Timber, Commercial, Custom, OpenHome, Unity Homes, Tektoniks
- Сетка 3 колонки (адаптивная → 1 колонка на мобильных)
- Карточка: изображение (250×375px), заголовок, подзаголовок
- Hover: тёмный overlay (75% opacity) + ссылка "Read more"
- Акцент активного фильтра: оранжевый (#d88739)
- 50+ проектов, newsletter-форма в подвале

**Страница отдельного проекта (пример: Contemporary Timberframe):**
- Название + локация (Holderness, New Hampshire)
- Карусель фотографий (Splide, 10 изображений)
- Спецификации: год, стиль, площадь (кв. футы), спальни, ванные
- Материалы: тип древесины, утепление (R-value), окна, отделка
- Описание удобств и особенностей
- Кредиты фотографу
- Навигация: кнопка "NEXT PROJECT"
- CTA: нет явного, только newsletter

### TimberFrameHQ (timberframehq.com)
- Галерея организована по категориям (интерьеры, экстерьеры, детали соединений)
- Образовательный контент интегрирован с портфолио
- Фокус на процессе строительства, не только результате

### OakFrameCompanies (oakframecompanies.co.uk)
- Сайт временно недоступен (503)
- По данным поиска: галерея по типам конструкций (дома, пристройки, гаражи)
- Акцент на традиционных английских oak frame технологиях

### Общие паттерны TF-компаний
- Фильтрация по типу конструкции (не по стилю интерьера)
- Акцент на древесину и соединения (визитная карточка TF)
- Спецификации: площадь, количество комнат, тип древесины
- Фото процесса: каркас до обшивки — КЛЮЧЕВОЙ дифференциатор
- Высокое качество фотографий (профессиональный фотограф)

## 4. Российские строительные сайты премиум-сегмента

### VERANDA Russia (veranda-russia.ru)
**Страница проекта — эталонная структура:**
- Видео-обзор конструкции
- 15+ фотографий с разных ракурсов
- 3 дизайн-концепции (визуализации)
- Таблица характеристик: форма, материал, размеры, серия, цвет, гарантия
- Хронологическая структура: задача → решение → фото → особенности
- Описание уникальных инженерных решений
- CTA: «Заказать индивидуальное решение», «Узнать больше»
- Стоимость НЕ указана (по запросу)

### ЛАТИТУДО (latitudo.ru/projects/terrasa/)
**Страница списка:**
- Сетка карточек (3 колонки)
- Карточка: фото + название + количество фото в проекте (например, «17 фото»)
- Логотип бренда материала (EasyDecking и т.д.)
- Боковое меню: 14 типов объектов
- Постраничная навигация
- CTA: «Закажите расчёт материалов», «Обсудить проект», видеоконсультация

### OliverDeck (oliverdeck.ru/proekty)
**Премиальное позиционирование:**
- Категории по типам конструкций + бюджетам
- Акцент на материалах (Бельгия, Швеция, Южная Корея)
- Скачиваемый каталог в PDF
- CTA: «Выезд замерщика», «Расчёт»
- Стоимость НЕ публичная

### Общие паттерны российских сайтов
- Стоимость почти никогда не указана (только «от X ₽/м²» или по запросу)
- Упор на количество фото и видео
- Мессенджеры (WhatsApp, Telegram) как основной канал связи
- Формы: «Расчёт стоимости», «Консультация», «Замерщик»
- Региональная привязка (город в заголовке/URL)
- Отзывы клиентов — отдельная секция или на отдельной странице

## 5. UX-паттерны (кросс-анализ)

### Обязательные элементы страницы списка портфолио
1. **Фильтры** по типу конструкции / категории
2. **Единообразные карточки** (фото + название + 1-2 ключевых параметра)
3. **Hover-эффект** с overlay или анимацией
4. **Адаптивная сетка** (3 колонки → 1 колонка)
5. **CTA** выше и ниже сетки

### Обязательные элементы страницы проекта
1. **Hero-галерея** (карусель или lightbox, 10-30 фото)
2. **Информационная карточка** (площадь, локация, год, тип)
3. **Описание** (задача клиента → решение → результат)
4. **Материалы и технологии**
5. **Навигация** к следующему/предыдущему проекту
6. **CTA** («Обсудить проект», «Рассчитать стоимость»)

### Продвинутые элементы (дифференциация)
- **До/После** слайдер
- **Видео-обзор** объекта
- **Фото процесса** (каркас, монтаж, этапы)
- **Отзыв клиента** встроенный в страницу проекта
- **3D-визуализация** или plan
- **Таблица характеристик** (структурированные данные)
- **Связанные проекты** (рекомендации)

## 6. SEO-подход для портфолио

### Schema Markup (JSON-LD)
```json
{
  "@context": "https://schema.org",
  "@type": "CreativeWork",
  "name": "Терраса из лиственницы — КП Репино",
  "description": "Открытая терраса 45 м² из лиственницы...",
  "image": ["url1.webp", "url2.webp"],
  "author": {
    "@type": "Organization",
    "name": "Timber Frame SPb"
  },
  "dateCreated": "2025-06",
  "locationCreated": {
    "@type": "Place",
    "name": "КП Репино, Ленинградская область"
  }
}
```

### Дополнительные schema-типы
- **LocalBusiness** — на уровне сайта
- **Service** — для каждого типа конструкции
- **ImageObject** — для фотографий проекта (alt, description, contentUrl)
- **Review** — для встроенных отзывов
- **BreadcrumbList** — навигация

### On-page SEO
- URL: `/portfolio/terrasa-iz-listvennicy-repino` (транслитерация)
- Title: `Терраса из лиственницы в Репино — 45 м² | Timber Frame SPb`
- H1: Название проекта
- Alt-тексты: «{ключевое слово} — {описание фото}»
- Internal links: к услуге, калькулятору, блогу
- Breadcrumbs: Главная > Портфолио > Террасы > Проект

### Контентная оптимизация
- Минимум 300 слов описания на страницу проекта
- Ключевые слова в первом абзаце
- Structured FAQ (если есть типовые вопросы по проекту)
- Фото с EXIF-данными (геолокация) — бонус для Google Images

## 7. Рекомендации для Timber Frame SPb

### Структура страницы списка (/portfolio)
1. Hero-секция с заголовком + подзаголовком
2. Фильтры: Все | Террасы | Веранды | Навесы | Перголы | Timber Frame
3. Сетка 3 колонки (карточки: фото + название + площадь + локация)
4. CTA: «Рассчитать стоимость вашего проекта»

### Структура страницы проекта (/portfolio/[slug])
1. **Hero-галерея** — карусель 10-20 фото (включая процесс)
2. **Sidebar** — площадь, локация, тип, год, материалы, стоимость «от»
3. **Описание** — задача клиента → решение → особенности
4. **Фото каркаса** — до обшивки (TF уникальность!)
5. **Материалы** — порода дерева, тип соединений, обработка
6. **Отзыв клиента** — цитата + имя
7. **CTA** — «Хочу такой же проект» / «Обсудить проект»
8. **Навигация** — Prev/Next проект
9. **Связанные проекты** — 3 похожих работы

### Приоритетные действия
1. Создать шаблон страницы проекта с sidebar-спецификациями
2. Добавить JSON-LD разметку (CreativeWork + ImageObject)
3. Реализовать фильтры по категориям
4. Фотографии процесса (каркас до обшивки) — обязательно для каждого проекта
5. Встроить отзывы в страницы проектов (не отдельная страница)
