# Timber Frame: Соединения и типология конструкций

## Типы соединений (Joinery)

### Основные — от простых к сложным

#### 1. Mortise & Tenon (Шип-паз)
- **Самое распространённое** соединение в TF
- Шип (tenon) входит в паз (mortise), фиксируется деревянными нагелями (pegs)
- Варианты: сквозной (through), глухой (blind), расклинённый (wedged)
- **Где**: стойка-балка, стойка-ригель — везде

#### 2. Through Tenon (Сквозной шип)
- Шип проходит насквозь, может расклиниваться с обратной стороны
- Прочнее глухого — видна фиксация
- **Где**: горизонтальные балки через стойки

#### 3. Tusk Tenon (Шип с клыком)
- Горизонтальный сквозной шип с внешним клином
- Несколько подтипов по форме клина
- **Где**: балки перекрытий

#### 4. Dovetail (Ласточкин хвост)
- Самоблокирующееся — не требует нагелей
- Трапецевидная форма шипа
- **Где**: зоны высоких нагрузок, стропила, балки

#### 5. Lap Joint / Half-Lap (Врубка вполдерева)
- Половина толщины каждого бруса срезается, элементы перекрещиваются заподлицо
- Простое, но менее прочное
- **Где**: пересечения горизонтальных элементов

#### 6. Scarf Joint (Накладное соединение)
- Соединение двух брусьев по длине (end-to-end)
- Клиновые, ступенчатые, молниеобразные варианты
- **Где**: удлинение балок и прогонов

#### 7. Tongue & Fork / Bridle Joint (Язычок и вилка)
- "Язык" одного стропила входит в "вилку" другого
- Может исключать коньковый прогон
- **Где**: конёк крыши

#### 8. Housed Joint (Врубка с посадкой)
- Неглубокий паз для торца + глубокий малый паз для шипа
- Прочнее обычного mortise & tenon
- **Где**: несущие узлы с высокой нагрузкой

#### 9. Knee Brace Joint (Подкосное соединение)
- Диагональные подкосы стойка↔балка
- Создают жёсткие треугольники, противостоят racking (боковому раскачиванию)
- **Где**: каждый угловой узел стойка-балка

#### 10. Spline Joint (Шпоночное)
- Отдельный элемент (обычно сухой дуб) через пазы в двух брусьях
- **Где**: стойка слишком узкая для двух шипов

#### 11. Bird's Mouth (Птичий рот)
- Вырез в стропиле для посадки на мауэрлат (wall plate)
- **Где**: стропильная система

#### 12. Lightning / Wedged Joints (Замковые / молниеобразные)
- Сложные фигурные соединения
- Немецкая и японская традиции
- **Где**: показательные конструкции, храмы

### Иерархия прочности
**Mortise & Tenon** > **Dovetail** > **Scarf Joints** (по несущей способности)

### Ключевой принцип
В true timber frame ВСЕ соединения — столярные. Металлический крепёж используется минимально (или не используется вообще). Это фундаментальное отличие от post-and-beam, где допускаются болты и стальные пластины.

## Типология конструкций

### 1. Bent Frame (Рамный каркас) — ОСНОВНОЙ ТИП
- Поперечные рамы (bents) = стойки + балки + ферма
- Рамы соединяются продольными прогонами (purlins)
- **Главный тип в Северной Америке**
- **Для террас/веранд**: самый подходящий — масштабируемый, понятный, красивый

### 2. Post-and-Beam (Стоечно-балочный)
- Вертикальные стойки + горизонтальные балки
- МОЖЕТ использовать металлический крепёж
- Технически НЕ true timber frame, если есть металл
- **Для террас**: проще, но менее "аутентичный"

### 3. Box Frame (Коробчатый каркас)
- Вертикальные стойки удерживаются горизонтальными балками
- 2-3 полных этажа
- Основа средневекового английского домостроения
- **Для зданий**, не для террас

### 4. Cruck Frame (Криволинейный / крюк-каркас)
- Пара изогнутых брёвен от фундамента до конька
- 4000+ зданий в Великобритании
- 6 подтипов: Full, Base, Raised, Middle, Upper, Jointed
- **Для показательных**: красиво, но сложно и дорого

### 5. Hammerbeam (Молотковая балка)
- Самый зрелищный тип
- Открытый центр (без нижней затяжки), большие пролёты
- Шедевр: Westminster Hall (1395, пролёт 20.7 м)
- **Для впечатления**: сложнейший тип, вершина мастерства

### 6. Aisled Frame (Нефный каркас)
- Внутренние ряды стоек делят на центральный неф + боковые
- Шире коробчатого каркаса
- **Для амбаров и больших зданий**

### 7. Fachwerk / Half-Timber (Фахверк)
- Каркас с заполнением (глина, кирпич, штукатурка)
- Каркас ВИДЕН снаружи
- Германия, Франция, Англия
- **В России**: основной коммерческий TF-продукт (клеёный брус + панорамное стекло)

### 8. Roundwood Timber Frame
- Каркас из необработанных круглых брёвен малого диаметра
- Современный тип (Ben Law)
- Ultra-sustainable, доступный
- **Для эко-проектов**: уникальный стиль

## Отличия Timber Frame от каркасного строительства (Stick Framing)

| Параметр | Timber Frame | Stick Framing (каркасник) |
|----------|-------------|--------------------------|
| Элементы | Массивный брус 150×150+ мм | Доска 38×140 мм (2×6) |
| Соединения | Столярные (mortise & tenon) | Гвозди, металлические пластины |
| Шаг стоек | 2-4 метра | 40-60 см |
| Стены | Не несущие (заполнение) | Несущие (обшивка = жёсткость) |
| Утепление | Снаружи каркаса (SIPs, PIR) | Внутри каркаса (минвата) |
| Видимость | Каркас видим изнутри (или снаружи — фахверк) | Каркас скрыт |
| Срок жизни | 100-500+ лет | 50-80 лет |
| Ремонтопригодность | Отдельные элементы заменяемы | Замена секциями стен |
| Стоимость | ×1.5-3 vs каркасник | Базовый уровень |
| Навыки | Столярное мастерство | Стандартные строительные |
