## 2. Дренаж (СП 250.1325800, СП 32.13330)

### Минимальные уклоны дренажных труб
| Тип грунта | Минимальный уклон |
|-----------|-----------------|
| Песчаный | **0,003** (3 мм/м.п.) |
| Глинистый | **0,002** (2 мм/м.п.) |
| Пластовый дренаж | **0,005–0,01** |

### Глубина укладки дренажа
- Закрытый дренаж: траншея глубиной **70–150 см**, ширина **25–40 см**
- Дренаж должен быть на **0,5 м глубже** подошвы фундамента
- Максимально допустимая скорость течения в трубе: **1 м/с**

## 3. Ливневая канализация (СП 32.13330.2018)

### Минимальные уклоны трубопроводов
| Диаметр трубы | Нормативный уклон | Допустимый минимум |
|-------------|-----------------|------------------|
| **150 мм** | 0,008 | 0,007 |
| **200 мм** | 0,007 | 0,005 |

### Водоотводные каналы (кюветы, канавы)
- Минимальная ширина по дну: **0,3 м**
- Минимальная глубина: **0,4 м**
- Сечение: трапецеидальное

## 4. Бетонные работы (СП 63.13330.2018)

### Марки бетона для площадок (рекомендации)
| Назначение | Класс бетона | Марка (ориент.) |
|-----------|-------------|----------------|
| Пешеходные дорожки | B15 | M200 |
| Отмостка, площадки без нагрузки | B15–B20 | M200–M250 |
| Площадки под авто (легковые) | B20–B22.5 | M250–M300 |
| Площадки под тяжёлую технику | B25+ | M350+ |

*Примечание: СП 63.13330 — общие положения по бетонным конструкциям. Для площадок конкретные марки определяются проектом по нагрузкам.*

### Толщина бетонной плиты площадки
- Пешеходная: **80–100 мм**
- Под легковой автомобиль: **120–150 мм**
- Под грузовой транспорт: **200+ мм**
- Армирование: сетка 100x100x4 или 150x150x5 для автомобильных площадок

## 5. Мощение тротуарной плиткой (ГОСТ 17608-2017)

### Параметры плитки
- Минимальная толщина: **40 мм** (отклонение до 5 мм)
- Крупный заполнитель: до **10 мм** (плитка ≤50 мм), до **20 мм** (плитка >50 мм)

### Пирог основания (типовой)
| Слой | Пешеходная зона | Под автомобиль |
|------|----------------|---------------|
| Тротуарная плитка | 40–60 мм | 60–80 мм |
| ЦПС (подстилающий) | 30–50 мм | 30–50 мм |
| Щебень (несущий) | 100–150 мм | 200–300 мм |
| Песок (выравнивающий) | 100–150 мм | 150–200 мм |
| Геотекстиль | + | + |
| **Итого** | **~300–400 мм** | **~500–650 мм** |

- Подстилающий слой: сухая ЦПС на цементе М300–М400
- Песчаный несущий — только для пешеходных зон с малой проходимостью
- Бетонный несущий — для зон с большой нагрузкой и проблемных грунтов

## 7. Грунты Ленинградской области

### Распространённые типы
- **Глинистые** (глины, суглинки) — преобладают
- **Песчаные** (пески, супеси) — часты в прибрежных зонах
- **Торфяные** — болотистые районы (Карельский перешеек, южное направление)
- **Скальные/крупнообломочные** — Карельский перешеек (гранитные породы)

### Уровень грунтовых вод (УГВ)
- В среднем **высокий** — характерная особенность региона
- В низинах и торфяниках: **0,5–1,0 м** от поверхности
- На возвышенностях и песках: **1,5–3,0 м**
- При высоком УГВ несущая способность грунта может снижаться **в 2+ раза**

### Несущая способность (ориентировочно, по СП 22.13330)
| Тип грунта | Расчётное сопротивление, кг/см² |
|-----------|-------------------------------|
| Скальный | 50–100+ |
| Крупный песок плотный | 5–6 |
| Средний песок | 4–5 |
| Мелкий песок | 2–3 |
| Супесь | 2–3 |
| Суглинок | 1,5–3 |
| Глина (твёрдая) | 3–6 |
| Глина (пластичная) | 1–2,5 |
| Торф | **Не основание** (требует замены/свай) |
