## Решение по хостингу (2026-04-01)

**Проблема:** Vercel — американский хостинг, IP могут быть заблокированы РКН. Риск для рекламной кампании.

**Исследование:** 4 агента параллельно исследовали:
1. **Amvera Cloud** — РФ аналог Vercel, 170-4300₽/мес, рубли
2. **Coolify на VPS** — self-hosted PaaS, 600-1200₽/мес, полный контроль
3. **Yandex Cloud** — Serverless Containers, холодный старт 1-10 сек (критично!)
4. **Cloudflare Proxy** — бесплатно, 30 мин настройка, скрывает origin IP

**Решение:** Двухэтапная миграция

### Этап 1: Cloudflare Proxy (СЕГОДНЯ)
- **Время:** 30 минут
- **Деньги:** 0₽
- **Что меняется:** DNS через Cloudflare, оранжевое облако скрывает IP Vercel
- **Защита:** IP Vercel скрыт от РКН

### Этап 2: Coolify на VPS (декабрь, межсезонье)
- **Время:** 45-60 минут (один раз)
- **Деньги:** ~800₽/мес (Timeweb VPS 4GB)
- **Что меняется:** Полная миграция с Vercel на свой VPS
- **Защита:** Полная независимость от санкций, ФЗ-152 compliance

**Why:** Сезон уже начался (апрель), нет времени на полную миграцию. Cloudflare даёт защиту быстро и бесплатно. Coolify — страховка на будущее.

**How to apply:** При планировании инфраструктуры: (1) Cloudflare Proxy для любого зарубежного хостинга, (2) Coolify как target для миграции в межсезонье.
