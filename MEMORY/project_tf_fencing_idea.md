Идея: развить направление ограждений и малых форм в конструктиве Timber Frame — заборы, калитки, ворота, элементы ландшафта в стиле фахверк.

**Why:** Естественное расширение линейки TF СПб. Конкуренты не предлагают TF-style заборы. Дифференциация через единый визуальный язык всего участка (терраса + забор + малые формы = один стиль).

**How to apply:** Зафиксировать как идею для Phase 2 сайта. Искать подрядчика на изготовление из других материалов (металл, камень + дерево). Включить в будущий контент-план и раздел сайта.
