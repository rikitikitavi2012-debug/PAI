## Рабочее время

### Типичное расписание
- **Основная работа:** 9:00 - 18:00 MSK (прораб, строительство)
- **Вечерние занятия:** 19:00 - 22:00 MSK (обучение, вайбкодинг, эксперименты с AI)
- **Часовой пояс:** Europe/Moscow (UTC+3)

### Пиковые часы
- **Deep Work (код/AI):** 19:00 - 22:00 (вечерние сессии)
- **Строительная работа:** 9:00 - 18:00 (дневное время)
- **Планирование/обучение:** Выходные утро

### Выходные
- Суббота, воскресенье — но часто используются для вайбкодинга и обучения

## Фокус и поток

### Как защитить фокус
- Вечерние сессии — основное время для кодинга, не прерывать
- Батчить уведомления, не отвлекать по мелочам

### Признаки потока
- Работа над одной задачей без переключения
- Активная итерация с AI-агентами
- Не проверяет мессенджеры

### Как помочь сфокусироваться
- Разбивать большие задачи на конкретные шаги
- Ставить чёткие критерии завершения (ISC)
- Предлагать MVP подход вместо идеального решения

## Управление задачами

### Система
- **Инструмент:** PAI TaskCreate/TaskList (встроенная система ISC)
- **Методология:** Algorithm-driven — каждая задача через ISC критерии
- **Проекты:** TELOS система для жизненных целей, PAI для технических задач

### Приоритеты задач
| Приоритет | Значение | Время реакции |
|-----------|----------|---------------|
| P0 | Критично (блокер) | Немедленно |
| P1 | Высокий (текущий фокус) | Сегодня |
| P2 | Средний (эта неделя) | Эта неделя |
| P3 | Низкий (когда будет время) | Когда возможно |

### Как представлять задачи
- [x] Упорядоченные по приоритету
- [x] С оценкой времени
- [ ] Сгруппированные по проекту
- [ ] С показанными зависимостями

## Принятие решений

### Быстрые решения
Сделать очевидный выбор и двигаться дальше. Не спрашивать для каждой мелочи.

### Важные решения
Представить варианты с трейд-оффами, дать Ivan выбрать. Формат AskUserQuestion.

### Когда спрашивать vs действовать
- **Спрашивать:** Деструктивные операции, деплой, выбор архитектуры, удаление файлов
- **Действовать и сообщать:** Рутинные задачи, форматирование, рефакторинг в рамках запроса

---

## Управление энергией

### Высокая энергия (даёт силы)
- Вайбкодинг — видеть результат работы AI
- Решение нестандартных задач через AI-агенты
- Создание инструментов автоматизации
- Быстрые итерации с видимым прогрессом

### Низкая энергия (забирает силы)
- Рутинная документация без результата
- Долгое ожидание без обратной связи (silent stalls)
- Повторение одних и тех же ошибок
- Ручная работа, которую можно автоматизировать

### Оптимизация
- Сложные задачи → вечерние deep work сессии
- Рутина → делегировать AI-агентам
- Обучение → короткие сфокусированные сессии с практикой

## Паттерны прокрастинации

### Что вызывает
- Нечёткие требования ("сделай что-нибудь с сайтом")
- Задачи кажущиеся огромными без разбивки
- Отсутствие видимого прогресса

### Как преодолеть
- Разбить на ISC критерии — каждый критерий = маленькая победа
- Начать с MVP — "работающий минимум" вместо "идеального решения"
- Использовать Algorithm как структуру — фазы дают прогресс

## Коммуникация

### Async vs Sync
- **Async:** Telegram, код-ревью, документация
- **Sync:** Голосовые звонки для срочного, live-coding сессии
