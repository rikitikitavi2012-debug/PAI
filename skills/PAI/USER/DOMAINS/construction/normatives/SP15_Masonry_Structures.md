## TL;DR (Краткая выжимка)
- **Выбрать материалы**: Определить марку кирпича/блока по прочности (например, М100) и марку кладочного раствора (например, М50) [п. 6.2, 6.13].
- **Проверить несущую способность**: Рассчитать центрально- и внецентренно-сжатые элементы (простенки, столбы) на прочность по формулам из раздела 9.
- **Учесть гибкость**: Обязательно проверить высокие и тонкие столбы и простенки на устойчивость. Гибкость `h_0/h` и `h_0/b` не должна превышать предельных значений [п. 9.17, табл. 9.3].
- **Правильно армировать**: Применять сетчатое армирование горизонтальных швов для повышения прочности кладки, особенно при больших нагрузках [п. 9.53].
- **Защитить от влаги**: Предусмотреть надёжную горизонтальную гидроизоляцию между фундаментом и первым рядом кладки для предотвращения капиллярного подсоса влаги [п. 11.2.1].

### Область применения
- Свод правил устанавливает требования к проектированию каменных и армокаменных конструкций, которые применяются в зданиях и сооружениях различного назначения [п. 1.1].
- Распространяется на кладку из кирпича, керамических, силикатных, бетонных камней и блоков.

### Ключевые определения
- **Каменная кладка**: Конструкция, состоящая из камней или блоков, уложенных в определённом порядке на строительном растворе [п. 3.1.6].
- **Марка камня/кирпича по прочности (М)**: Характеристика прочности камня на сжатие (например, М100, М150) [ГОСТ 530].
- **Марка раствора по прочности (М)**: Характеристика прочности затвердевшего кладочного раствора на сжатие (например, М50, М100) [ГОСТ 28013].
- **Расчетное сопротивление кладки (R)**: Несущая способность кладки, которая зависит от марок камня и раствора и принимается по таблицам СП [п. 7.1].

### Таблицы норм и минимальные требования
- **Таблица 2**: Расчётные сопротивления сжатию кладки `R` в зависимости от марки кирпича/камня и марки раствора. Это ключевая таблица для всех расчётов на прочность [табл. 2].
- **Таблица 9.3**: Предельные значения гибкости (`h_0/h`) для сжатых элементов (столбов, простенков). Несоблюдение этих значений ведёт к потере устойчивости [табл. 9.3].
- **Пункт 9.16**: Формулы для определения расчётной высоты `h_0` сжатых элементов в зависимости от условий их закрепления.

### Пошаговое применение для опорных столбов террасы
1.  **Собрать нагрузку `N`**: По данным из `SP20_Loads_and_Impacts.md` определить полную вертикальную нагрузку на один опорный столб.
2.  **Выбрать материалы**: Задать марку кирпича (например, полнотелый М150) и марку раствора (например, М75).
3.  **Определить расчётное сопротивление `R`**: По таблице 2 на пересечении марки кирпича и марки раствора найти `R`.
4.  **Подобрать сечение столба**: Площадь сечения столба `A` должна удовлетворять условию прочности `A ≥ N / (φ * R)`, где `φ` — коэффициент продольного изгиба. Для предварительного подбора можно принять `φ` ≈ 0.8-0.9.
5.  **Проверить устойчивость**: Рассчитать фактическую гибкость столба и сравнить её с предельной по таблице 9.3. Если гибкость превышена — увеличить сечение столба.
6.  **Назначить армирование**: Для столбов, воспринимающих значительные нагрузки, предусмотреть армирование кладки сетками через каждые 4-5 рядов кладки [п. 9.53].

### Формулы и коэффициенты (если применимо)
- **Расчет центрально-сжатых элементов на прочность**: ( N \\le R \\cdot A_n ), где `A_n` — площадь сечения нетто [п. 9.1].
- **Расчет на устойчивость (продольный изгиб)**: ( N \\le \\varphi \\cdot R \\cdot A ), где `φ` (phi) — коэффициент продольного изгиба, зависящий от гибкости элемента.
- **Коэффициент `ω` (omega)**: Дополнительный коэффициент в формулах прочности, учитывающий длительное действие нагрузки. При расчёте на постоянные и длительные нагрузки `ω` > 1.0, что снижает несущую способность [п. 9.5].

### Типовые ошибки и как избежать
- **Ошибка**: Применение силикатного кирпича или газобетонных блоков для кладки цоколей и стен подвалов без должной гидроизоляции. Эти материалы боятся влаги.
  - **Как правильно**: Для подземных и цокольных частей использовать полнотелый керамический кирпич или бетонные блоки.
- **Ошибка**: Несоответствие марки раствора марке кирпича (например, использование слабого раствора М25 для высокопрочного кирпича М150). Прочность кладки определяет раствор.
  - **Как правильно**: Использовать марку раствора, которая позволяет получить требуемое расчётное сопротивление `R` по таблице 2.
- **Ошибка**: Отсутствие армирования кладки в местах опирания балок и перемычек, где возникают концентрации напряжений.
  - **Как правильно**: Предусматривать армирующие сетки под и над опорными зонами.

## 1. Key Excerpts

Данный Свод правил устанавливает требования к проектированию каменных и армокаменных конструкций из кирпича, камней, бетонных и ячеистобетонных блоков.

-   **Материалы:** Следует применять камни и растворы, марки по прочности и морозостойкости которых соответствуют проектным требованиям и условиям эксплуатации.
-   **Расчет прочности:** Расчет элементов каменных конструкций производят по предельным состояниям первой группы (по несущей способности) и второй группы (по образованию или раскрытию трещин и по деформациям).
-   **Армирование:** Следует предусматривать конструктивное армирование для повышения прочности, а также в случаях, когда необходимо предотвратить образование трещин от усадки, температуры и других воздействий.
-   **Гибкие связи:** При проектировании многослойных стен необходимо предусматривать гибкие связи между внутренним и наружным слоями для обеспечения их совместной работы.

## 2. Area of Application

Требования СП обязательны при проектировании несущих и ограждающих стен кирпичных и блочных пристроек, столбов и колонн для террас и навесов, а также цоколей зданий.

## 5. Calculation Algorithms (Pseudo-code)

**Алгоритм 8: Расчет несущей способности центрально-сжатого простенка**
1.  **INPUT:** `height (h)`, `thickness (t)`, `load (N)`, `masonry_unit_grade`, `mortar_grade`.
2.  `R = GET_MASONRY_STRENGTH(masonry_unit_grade, mortar_grade)` // Расчетное сопротивление кладки
3.  `phi = GET_BUCKLING_COEFFICIENT(h, t)` // Коэффициент продольного изгиба
4.  `Area = t * length`
5.  `// Проверка условия прочности`
6.  `check_ratio = N / (phi * Area * R)`
7.  `IF check_ratio <= 1 THEN RETURN 'PASS' ELSE RETURN 'FAIL (ratio: ' + check_ratio + ')'`

## 8. Typical Design Flaws (for AI detection)

1.  **`Flaw ID: NO_REINFORCEMENT`**: Проектирование стены из газобетона длиной 6 метров без устройства горизонтального армирования кладки в швах (требуется армирование сеткой или арматурой каждые 3-4 ряда). **Риск:** Появление сквозных вертикальных трещин в первый же год.
2.  **`Flaw ID: IMPROPER_ANCHORING`**: Жесткое крепление (перевязка кладкой) стены кирпичной пристройки к стене основного деревянного дома. **Риск:** Образование вертикальной трещины по всей высоте примыкания из-за разной усадки материалов.
3.  **`Flaw ID: WRONG_MORTAR_TYPE`**: Использование для кладки поризованных керамических блоков ("теплой керамики") обычного цементно-песчаного раствора со швом 10-12 мм. **Риск:** Создание "мостиков холода", которые сводят на нет до 30% теплоэффективности стены.
4.  **`Flaw ID: NO_DAMP_PROOFING`**: Отсутствие горизонтальной отсечной гидроизоляции между фундаментом и первым рядом кладки. **Риск:** Капиллярный подсос влаги из фундамента, намокание стены, появление плесени и высолов.
