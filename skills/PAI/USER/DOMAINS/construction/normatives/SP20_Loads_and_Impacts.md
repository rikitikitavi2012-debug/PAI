## TL;DR (Краткая выжимка)
- **Взять нормативные значения**: `Sg` (снег) и `W0` (ветер) из `SP131_Climatology.md` для вашего региона.
- **Рассчитать полный снег `S`**: Умножить `Sg` на коэффициент перехода `μ` (зависит от уклона кровли) и коэффициент надёжности `γ_f` = 1,4.
- **Рассчитать полный ветер `W`**: Умножить `W0` на аэродинамический коэффициент `c` и коэффициент `k(z)`, учитывающий высоту и тип местности.
- **Сложить нагрузки**: Проверить конструкции на действие сочетаний нагрузок (например, постоянные + снеговая; постоянные + ветровая).

### Мини-формуляр для расчёта
- **Расчётная снеговая нагрузка `S`**:
  `S = Sg * μ * Ce * Ct * γ_f`
  - `Sg` — нормативное значение веса снегового покрова, кПа (из `SP131_Climatology.md`)
  - `μ` — коэффициент перехода от веса снегового покрова к снеговой нагрузке (зависит от уклона α, [Приложение Д])
  - `Ce` — коэффициент сноса снега (обычно 1,0) [п. 10.5]
  - `Ct` — термический коэффициент (обычно 1,0) [п. 10.6]
  - `γ_f` — коэффициент надёжности по нагрузке (для снега = 1,4) [п. 10.12]
- **Расчётная ветровая нагрузка `W`**:
  `W = W0 * k(z_e) * c * γ_f`
  - `W0` — нормативное значение давления ветра, кПа (из `SP131_Climatology.md`)
  - `k(z_e)` — коэффициент, учитывающий изменение давления ветра по высоте (берётся по таблице 11.2)
  - `c` — аэродинамический коэффициент (берётся по Приложению Г)
  - `γ_f` — коэффициент надёжности по нагрузке (для ветра = 1,4) [п. 11.1.11]

### Мини-гайд: Расчёт навеса веранды (5 шагов)
1.  **Исходные данные (Москва)**: `Sg` = 1,5 кПа. Уклон кровли навеса `α` = 10°.
2.  **Найти коэффициент `μ`**: Для односкатной кровли с уклоном `α` ≤ 30°, коэффициент `μ` = 1,0 [Приложение Д, схема Д.1].
3.  **Рассчитать полную снеговую нагрузку `S`**:
    `S = 1,5 кПа * 1,0 * 1,4 = 2,1 кПа` (или 210 кгс/м²).
4.  **Определить грузовую площадь**: Если шаг стропил = 0,8 м, то нагрузка на 1 погонный метр стропила `q` = `S * 0,8 м` = `2,1 кПа * 0,8 м` = 1,68 кН/м.
5.  **Передать в расчёт**: Полученная нагрузка `q` используется для расчёта прочности стропил, балок и стоек в `SP64_Wooden_Structures.md` или `SP16_Steel_Structures.md`.

### Ключевые определения
- **Постоянные нагрузки (G)**: Вес несущих и ограждающих конструкций, вес грунта.
- **Длительные временные нагрузки**: Вес стационарного оборудования, длительно складируемых материалов.
- **Кратковременные нагрузки (Q)**: Снеговые, ветровые, нагрузки от людей и подвижного оборудования.

## 1. Key Excerpts

Данный Свод правил (актуализированная редакция СНиП 2.01.07-85*) устанавливает требования по назначению нагрузок, воздействий и их сочетаний, которые необходимо учитывать при расчетах зданий и сооружений по предельным состояниям.

-   **Классификация нагрузок:** Нагрузки разделяются на постоянные (вес несущих и ограждающих конструкций) и временные (длительные, кратковременные, особые).
    -   **Длительные:** вес стационарного оборудования, перегородок и т.д.
    -   **Кратковременные:** снеговые, ветровые нагрузки, нагрузки от подвижного оборудования, людей.
    -   **Особые:** сейсмические, взрывные, пожарные нагрузки.
-   **Расчетные значения:** Для расчетов используются расчетные значения нагрузок, которые определяются умножением нормативного значения на коэффициент надежности по нагрузке (`γf`).
-   **Сочетания нагрузок:** СП устанавливает правила для основных и особых сочетаний нагрузок, учитывая вероятность их одновременного действия с помощью коэффициентов сочетаний.
-   **Снеговые и ветровые нагрузки:** Являются одними из ключевых кратковременных нагрузок. Их нормативное значение зависит от региона строительства (снегового и ветрового района), который определяется по картам в приложениях к СП.

## 2. Area of Application

Требования данного СП являются обязательными при проектировании конструкций для всех видов зданий и сооружений, за исключением атомных электростанций, гидротехнических и некоторых других специальных сооружений. **Для малоэтажного строительства (террасы, веранды, беседки, навесы)** данный документ является основополагающим для:

-   Расчета прочности фундамента.
-   Выбора сечения балок, стоек и стропил.
-   Определения конструкции кровли и ее креплений.

## 5. Calculation Algorithms (Pseudo-code)

**Цель:** Предоставить пошаговые алгоритмы для типовых расчетов.

**Алгоритм 1: Расчет снеговой нагрузки для навеса (Москва):**
1.  **Определить снеговой район:** Москва → III район.
2.  **Получить базовую нагрузку (Sg):** Для III района `Sg = 1.5 кПа` (150 кг/м²).
3.  **Определить коэффициент формы (µ):** Для односкатного навеса с углом < 30°, `µ = 0.8`.
4.  **Рассчитать нормативную нагрузку (S_norm):** `S_norm = Sg * µ = 1.5 * 0.8 = 1.2 кПа`.
5.  **Рассчитать расчетную нагрузку (S_calc):** `S_calc = S_norm * γf = 1.2 * 1.4 = 1.68 кПа`.

## 8. Typical Design Flaws (for AI detection)

**Цель:** Обучить AI распознавать и предотвращать типовые ошибки проектирования.

1.  **`Flaw ID: SNOW_POCKET`**: Не учтен повышенный коэффициент `µ` (от 1.5 до 2.0) для снегового мешка в месте примыкания односкатной крыши пристройки к стене основного здания. **Риск:** Локальное обрушение кровли.
2.  **`Flaw ID: WIND_UPLIFT`**: Не проведен расчет на ветровой отрыв (действие подъемной силы, отрицательный коэф. `c`) для легких навесов с большим выносом. **Риск:** Отрыв кровельного покрытия или всей конструкции.
3.  **`Flaw ID: RAILING_LOAD`**: Горизонтальная нагрузка на перила и ограждения террас рассчитана как кратковременная, а не длительная (для мест возможного скопления людей). **Риск:** Обрушение ограждений.
