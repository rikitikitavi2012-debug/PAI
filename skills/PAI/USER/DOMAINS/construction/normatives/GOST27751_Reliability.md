# GOST27751_Reliability

**Version:** 1.0
**Last Updated:** 2025-11-03

## 1. Key Excerpts

Данный межгосударственный стандарт устанавливает общие принципы обеспечения надежности строительных конструкций и оснований на всех этапах жизненного цикла: при проектировании, строительстве, эксплуатации, реконструкции и сносе.

-   **Надежность:** Способность строительного объекта выполнять требуемые функции в течение расчетного срока эксплуатации, сохраняя свои эксплуатационные показатели в установленных пределах.
-   **Предельные состояния:** Вводятся две группы предельных состояний: 1-я группа (полная непригодность к эксплуатации, разрушение) и 2-я группа (затруднение нормальной эксплуатации, например, большие прогибы).
-   **Уровни ответственности:** Здания и сооружения подразделяются на три уровня ответственности: повышенный (КС-3), нормальный (КС-2) и пониженный (КС-1).
-   **Коэффициенты надежности:** Для обеспечения надежности в расчетах используются коэффициенты надежности по нагрузке (`γf`), по материалу (`γm`), по условиям работы (`γc`) и по ответственности (`γn`).

## 2. Area of Application

Требования ГОСТ являются основополагающими для всех нормативных документов, используемых при проектировании и расчете (СП по нагрузкам, СП по деревянным, стальным, ж/б конструкциям и т.д.). Для этот документ является **верхнеуровневым "контролером"**, определяющим общие правила и запасы прочности.

## 7. Quick Reference Tables

**Таблица 3: Коэффициент надежности по ответственности (γn) (Таблица 4 из ГОСТ)**

| Класс сооружения | Уровень ответственности | `γn` |
|---|---|---|
| КС-3 | Повышенный | ≥ 1.1 |
| КС-2 | Нормальный | 1.0 |
| КС-1 | Пониженный | ≥ 0.9 |

*Примечание: Для объектов класса КС-1 и КС-3 значение коэффициента может быть уточнено в задании на проектирование.*

## 8. Typical Design Flaws (for AI detection)

1.  **`Flaw ID: CLASS_NOT_DEFINED`**: Проект передан на финальный расчет без явно присвоенного класса ответственности. **Риск:** Расчеты не могут считаться валидными, так как не определен общий запас прочности.
2.  **`Flaw ID: GAMMA_N_MISSED`**: Коэффициент `γn` не был применен к расчетным значениям нагрузок, что является прямым нарушением ГОСТ. **Риск:** Недооценка нагрузок на 10% (для КС-1), снижение реального запаса прочности.
3.  **`Flaw ID: WRONG_CLASS_ASSIGNMENT`**: Отапливаемой пристройке к жилому дому (объект КС-2) ошибочно присвоен класс КС-1, как для отдельно стоящей беседки. **Риск:** Проектирование с заниженным запасом прочности для конструкции, являющейся частью жилого дома.

## 9. Responsibility Level Classification

**Цель:** Однозначная классификация объектов.

-   Согласно п. 10.1 ГОСТ 27751-2014 и Приложению А, все отдельно стоящие сооружения (террасы, беседки, навесы, летние кухни) как объекты сезонной эксплуатации и вспомогательного назначения относятся к **классу КС-1 (пониженный уровень ответственности)**. Для них `γn` принимается равным **0.9**.
-   Отапливаемые веранды и пристройки, конструктивно связанные с жилым домом (объект класса КС-2), также должны быть отнесены к **классу КС-2 (нормальный уровень ответственности)**. Для них `γn` принимается равным **1.0**.
