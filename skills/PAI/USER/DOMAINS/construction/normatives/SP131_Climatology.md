  - `W0` (нормативная ветровая): 0,23 кПа (23 кгс/м²) [табл. И.1]

## 1. Key Excerpts

Данный Свод правил устанавливает климатические параметры, которые должны использоваться при проектировании зданий, сооружений и их инженерных систем (отопление, вентиляция).

-   **Климатические параметры:** Документ содержит параметры температуры воздуха (средние, экстремальные), влажности, данные по ветру, осадкам, солнечной радиации и гололедно-ветровым нагрузкам.
-   **Районирование:** Территория РФ разделена на климатические районы и подрайоны, для каждого из которых приведены свои нормативные значения.
-   **Актуализация данных:** СП 131.13330.2025 включает обновленные данные, полученные за последние периоды наблюдений, что повышает точность расчетов по сравнению с предыдущими редакциями (например, СП 131.13330.2020).

## 2. Area of Application

Требования СП являются обязательными при проектировании и реконструкции. Для этот документ является **основным источником исходных данных** для:

-   Расчета снеговых и ветровых нагрузок (ссылаясь на `SP20_Loads_and_Impacts.md`).
-   Расчета глубины промерзания грунта (ссылаясь на `SP22_Foundations.md`).
-   Выбора коэффициентов условий работы для деревянных конструкций (ссылаясь на `SP64_Wooden_Structures.md`).
-   Расчета теплопотерь для отапливаемых пристроек.

## 8. Typical Design Flaws (for AI detection)

1.  **`Flaw ID: OUTDATED_DATA`**: Расчет снеговой нагрузки для Санкт-Петербурга выполнен по данным СП 131.13330.2020 (Снеговой район II), тогда как в новой редакции СП 131.13330.2025 город отнесен к району III. **Риск:** Недооценка снеговой нагрузки на ~25%, возможное обрушение кровли.
2.  **`Flaw ID: WRONG_REGION`**: Применение для участка в г. Сочи (побережье, ветровой район IV) данных г. Краснодара (ветровой район III). **Риск:** Недостаточное закрепление кровельного покрытия, срыв листов при сильном ветре.
3.  **`Flaw ID: HUMIDITY_IGNORE`**: Проектирование открытой террасы из дерева в г. Санкт-Петербург (зона влажности "влажная") без применения понижающего коэффициента `k_h=0.7` для расчетного сопротивления древесины. **Риск:** Ускоренная потеря несущей способности деревянных балок и стоек.

## 10. Comfort & Economy Score Algorithm

**Цель:** Расчет интегральных показателей для консультирования клиента.

**Алгоритм 1: "Индекс Инсоляции" (для террас и веранд)**
1.  `solar_rad = GET_CLIMATE_DATA(region, 'annual_solar_radiation_vertical')`
2.  `IF solar_rad > 1200 THEN return "Высокий. Ваша терраса будет солнечной большую часть года, идеально для отдыха."`
3.  `ELSE IF solar_rad > 1000 THEN return "Средний. Достаточно солнца для комфортного использования с весны по осень."`
4.  `ELSE return "Умеренный. Рекомендуем рассмотреть прозрачную кровлю для увеличения освещенности."`

**Алгоритм 2: "Индекс Экономии на Отоплении" (для отапливаемых пристроек)**
1.  `heating_days = GET_CLIMATE_DATA(region, 'heating_period_days')`
2.  `IF heating_days > 220 THEN return "Критически важно. Качественное утепление окупится за 2-3 сезона."`
3.  `ELSE IF heating_days > 180 THEN return "Очень важно. Рекомендуем утепление стен 150мм и кровли 200мм."`
4.  `ELSE return "Важно. Стандартного утепления будет достаточно."`
