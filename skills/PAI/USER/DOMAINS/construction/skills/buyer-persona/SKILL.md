# Skill: Buyer Persona (Аватар клиента)

## Цель
Создать детальные портреты целевых клиентов на основе данных рынка, конкурентов, SEO-ядра и бизнес-стратегии. Персоны становятся фундаментом для всех решений по сайту.

## Входные данные
- Бизнес-стратегия (STRATEGY.md)
- База конкурентов (COMPETITOR_DATABASE.md)
- Анализ сайтов конкурентов (COMPETITOR_WEBSITES.md)
- SEO семантическое ядро (SEO_SEMANTIC_CORE.md)
- Прайс-лист работ (PRICE_LIST_WORKS.md)
- Бизнес-процессы (processes/)

## Методология

### 1. Сегментация аудитории
- Анализ ценовых сегментов из прайс-листа и стратегии
- Кластеризация поисковых запросов по интенту (информационный / коммерческий / навигационный)
- Определение 2-3 ключевых сегментов по пересечению цены и интента

### 2. Построение персоны (для каждого сегмента)
**Демография:** имя, возраст, пол, семья, доход, район, профессия
**Психография:** ценности, отношение к дому, определение "качества", страхи, мотивация
**Поведение:** каналы поиска, запросы (из SEO-ядра), количество сравнений, решающие факторы, стоп-факторы, цикл решения
**Возражения:** топ-5 барьеров + как сайт их снимает + необходимый контент/функционал
**JTBD:** функциональная, эмоциональная, социальная задачи
**Customer Journey Map:** триггер → осознание → исследование → сравнение → выбор → заказ → ожидание → результат

### 3. Валидация
- Каждая персона привязана к конкретным SEO-кластерам
- Каждая персона привязана к конкретному ценовому сегменту
- Поведенческие паттерны подтверждены данными конкурентов

## Формат выхода
Markdown-файл `BUYER_PERSONAS.md` с 2-3 персонами, каждая по полной структуре.

## Критерии качества
- [ ] Минимум 2 персоны, максимум 3
- [ ] Каждая персона содержит ВСЕ разделы методологии
- [ ] Каждое утверждение ссылается на источник данных (файл)
- [ ] Отсутствуют выдуманные статистики — пробелы помечены "ДАННЫЕ ОТСУТСТВУЮТ"
- [ ] SEO-запросы привязаны к конкретным персонам
- [ ] Customer Journey Map включает рекомендации по контенту сайта на каждом этапе
- [ ] Персоны покрывают весь целевой диапазон (не только один тип клиента)
