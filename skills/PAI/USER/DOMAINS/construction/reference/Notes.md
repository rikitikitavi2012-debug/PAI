## Заметки по структуре

- Файлы нормативов содержат: ключевые определения, формулы, алгоритмы расчета в псевдокоде, таблицы допусков, типовые ошибки, чек-листы валидации
- Шаблоны проектов включают: BOM (ведомость материалов), этапы работ, привязку к нормативам
- Компоненты -- переиспользуемые узлы, которые подключаются к шаблонам проектов
- NORM_09 нуждается в добавлении раздела "Key Definitions" (заметка из оригинала)
- Лимит оригинальной системы: 50 файлов (в PAI это ограничение не действует)
