## 1. Позиционирование

**Формула проекта:**
Construction Orchestrator = Vertical SaaS (строительство) + Niche (МАФ, соло-предприниматель) + Lightweight (без ERP-балласта) + AI-First (Gemini как мозг)

**3 блока системы:**
1. **Клиентский портал** — лендинг с AI-конфигуратором, лидогенерация
2. **Оркестратор** — CRM + AI-сметы + RAG база знаний + n8n автоматизация
3. **Поле прораба** — мобильный контроль, чек-листы, фото-фиксация

**Целевая аудитория (двойная):**
- **B2C:** Владельцы премиум-коттеджей (500K+ ₽/мес, 35-60 лет, СПб/МО)
- **B2B (будущее SaaS):** Компании типа "Создай Террасу" (15-30K ₽/мес)

## 5. Go-to-Market стратегия (дек. 2025)

### Двойной путь

**Путь 1: Как строитель (B2C) — персональная стратегия Ivan:**
- Локация: Бугры → Онегин Парк → Елагино → СПб
- Модель: консультация (15K) → проектирование (50K) → строительство (300-600K)
- Каналы: Instagram, Telegram, LinkedIn, холодные звонки
- Год 1 прогноз: 1.3-1.7М ₽ выручка (только проектирование)

**Путь 2: Как SaaS (B2B) — для строительных компаний:**
- TAM: 50-100 узкоспециализированных + 5-10K универсальных
- SOM: 3-5 первых клиентов → 15-25 за год
- Цена: 15-30K ₽/мес
- LTV/CAC: 25.7x (отличный)

### 100-дневный план
1. Дни 1-14: Подготовка (аккаунты, портфолио, прайс)
2. Дни 15-28: Холодные контакты (25/день)
3. Дни 29-56: Первые консультации и сделки
4. Дни 57-84: Масштабирование рекламы
5. Дни 85-100: Первые завершённые проекты

## 6. Формула лендинга

**Конверсия[%] = (0.30×H + 0.25×M + 0.20×T + 0.15×C + 0.10×A) × K_регион**

**Оптимальная структура (10 блоков):**
1. HERO — видео конфигуратора + CTA "Спроектировать"
2. Проблема + AI-решение (сравнение: 10 дней vs 2 минуты)
3. AI-конфигуратор (интерактивный)
4. Результат: смета + 3D + договор
5. Материалы (3 карточки + таблица)
6. Процесс: 4 этапа вместо 40 дней
7. Социальное доказательство (500+ проектов)
8. FAQ (боли клиентов)
9. Финальный CTA
10. Footer + Trust

**SEO-ключи:** "терраса под ключ [город]", "онлайн калькулятор террасы", "фиксированная смета без доплат"

## 7. Архитектура SmartEstimator Pro v3.0

**Текущая:** React SPA → линейный workflow → localStorage
**Целевая (v3.0):** Full-stack (NestJS + Postgres) → Lead-to-Cash → Graph of Thoughts + INoT

**Ключевые трансформации:**
- PII Proxy для 152-ФЗ (обезличивание данных перед отправкой в Gemini)
- GoT для вариативных смет (Эконом/Стандарт/Премиум)
- Интеграция с поставщиками (Петрович API)
- Генерация КС-2/КС-3
- Мобильное PWA для стройплощадки

**Риски:**
1. **Блокировка Google API** (санкции) → абстракция AIService → GigaChat/YandexGPT fallback
2. **Галлюцинации AI** в сметах → Battle Mode (сравнение с матрицей цен)
3. **152-ФЗ** → локальное хранение ПДн, PII-проксирование
4. **Консерватизм прорабов** → Foreman Mode (проще WhatsApp)
