## 3. УЗКИЕ МЕСТА (разрывы между стратегией и реализацией)

### Разрыв 1: Амбициозная архитектура vs Реальные ресурсы
- **Стратегия говорит:** SmartEstimator Pro v3.0 = NestJS + Postgres + GoT + INoT + PWA + n8n + Supabase + PII Proxy
- **Реальность:** Ivan — соло-предприниматель, прораб, не разработчик. Бюджет ограничен.
- **Вывод:** Нужна MVP-версия, а не Enterprise-архитектура. Текущий PAI Dashboard (Next.js + Supabase + Vercel) — правильный подход, но Obsidian описывает совсем другой стек (Google AI Studio + Beget).

### Разрыв 2: Два конфликтующих tech-стека
- **Obsidian:** React 18 + Gemini API + Beget + n8n + Google AI Studio
- **PAI Dashboard:** Next.js + Supabase + Vercel + Claude/PAI
- **Вывод:** Нужно решить — это один проект или два разных. Сейчас создаётся путаница.

### Разрыв 3: B2C строитель vs B2B SaaS платформа
- **Персональная стратегия:** Ivan как прораб продаёт услуги напрямую клиентам
- **SaaS стратегия:** Construction Orchestrator как продукт для других компаний (15-30K/мес)
- **Вывод:** Нельзя делать оба пути одновременно. Нужно выбрать: сначала B2C (строить, зарабатывать, собирать кейсы), потом B2B (автоматизировать и продавать систему).

### Разрыв 4: Маркетинговые планы не начаты
- **30-дневный план (дек. 2025)** предполагал создание Instagram, 10 холодных звонков/день, реклама
- **Февраль 2026:** Прошло ~2.5 месяца, а маркетинговые каналы (Instagram, Telegram канал для террас) судя по контексту не созданы
- **Вывод:** План устарел. Нужна реактуализация с учётом реального прогресса.

### Разрыв 5: Лендинг спроектирован, но не реализован
- **Landing_Formula_Report:** Детальный 10-блочный макет с конверсионной формулой
- **SmartLanding_v2.0.tsx:** Есть код компонента
- **Реальность:** Лендинг не задеплоен. PAI Dashboard — это дашборд PAI системы, не лендинг для клиентов.

## 8. РЕЗУЛЬТАТЫ ИССЛЕДОВАНИЯ (фев. 2026)

Проведено веб-исследование по 5 направлениям. Ключевые находки:

### Конкурентный ландшафт (обновлено)
- Ниша специализированных террасных компаний в СПб **остаётся слабо конкурентной**
- «Создай Террасу» сохраняет позиции; новых крупных игроков не обнаружено
- Появились московские игроки: OliverDeck, Deckson (ДПК-специализация)
- DerevoParк — премиальный ландшафтный дизайн, потенциальный конкурент в сегменте

### Цены (актуализация)
- ДПК Москва: материал от 1,380 ₽/м², под ключ ~4,000-4,500 ₽/м²
- Лиственница СПб: от 1,400 ₽/м² (сорт АВ) до 10,000 ₽/м² (экстра)
- Рост цен по сравнению с дек. 2025 — **незначительный** (в пределах инфляции)

### ConTech AI в РФ
- Минстрой запустил **Платформу данных строительной отрасли**
- ГИС ОГД: **236 млн объектов** в базе
- Рынок AI в РФ: ×1.5 рост ежегодно, проект продлён до 2030
- **Прямых AI-конкурентов для нишевого Construction Orchestrator в РФ НЕ обнаружено** — окно возможностей открыто

### Тренды МАФ 2025-2026
- Экологичность (70-80% МАФ из дерева), модульность, smart-МАФ
- Биоморфизм и органические формы — плавные линии вместо прямых
- LED-подсветка как художественный элемент
