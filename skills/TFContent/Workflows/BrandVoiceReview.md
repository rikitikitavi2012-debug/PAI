# BrandVoiceReview — Workflow

> Проверка и корректировка текста на соответствие голосу бренда Timber Frame.

---

## Входные данные
- Текст для проверки (статья, описание, заголовок)

## Шаги

### 1. Загрузить эталон
```
READ ~/.claude/skills/TFContent/TFBrandVoice.md
```

### 2. Проверка по чеклисту

| Критерий | Проверка | Вес |
|----------|----------|-----|
| Запрещённые фразы | Поиск 8 антипаттернов из TFBrandVoice.md | Критический |
| Конкретика | Есть ли цифры в каждом абзаце? | Высокий |
| Тон | Expert + Informal + Concrete? | Высокий |
| Персона | Язык соответствует целевой аудитории? | Средний |
| CTA | Конкретное действие, не абстрактное? | Средний |
| Длина предложений | Средняя < 20 слов? | Низкий |

### 3. Формат отчёта

```markdown
## Brand Voice Review

**Текст:** [первые 50 символов...]
**Персона:** [определена/не определена]
**Оценка:** [X/10]

### Нарушения
1. 🔴 [Критическое: запрещённая фраза "..."]
2. 🟡 [Среднее: нет конкретной цены в секции X]
3. 🟢 [Мелкое: предложение слишком длинное (32 слова)]

### Исправленная версия
[Полный текст с исправлениями]

### Что хорошо
- [Конкретные сильные стороны текста]
```

### 4. Автокоррекция

При обнаружении нарушений — предложить исправленную версию:
- Запрещённые фразы → конкретные замены
- Отсутствие цифр → добавить из TFExpertise.md
- Неверный тон → переписать в правильном ключе
