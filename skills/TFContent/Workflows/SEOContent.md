# SEOContent — Workflow

> SEO-оптимизация контента: meta descriptions, keyword integration, аудит страниц.

---

## Варианты использования

### 1. Аудит существующей страницы
```
Вход: URL или файл страницы
Выход: Отчёт с рекомендациями + исправленные мета-теги
```

**Шаги:**
1. Прочитать содержимое страницы
2. Загрузить SEO-ядро из TFExpertise.md (секция 7)
3. Проверить:
   - H1 содержит primary keyword?
   - H2-H3 содержат secondary keywords?
   - Meta description 150-160 chars с ключевым словом?
   - Alt-тексты изображений содержат ключевые слова?
   - Внутренние ссылки на другие страницы (≥2)?
   - Нет keyword stuffing (плотность < 3%)?
4. Выдать таблицу результатов + исправленные варианты

### 2. Создание meta descriptions
```
Вход: Список страниц
Выход: Meta description для каждой страницы
```

**Формула:** `[Ключевое слово] в СПб от [цена] ₽/м². [Конкретика]. [CTA].`

**Ограничения:**
- 150-160 символов (Яндекс обрезает длиннее)
- Ключевое слово в первых 60 символах
- CTA в конце (глагол: Рассчитайте, Посмотрите, Закажите)
- Цена или конкретная цифра обязательна

### 3. Keyword mapping
```
Вход: Новая страница или статья
Выход: Список целевых ключевых слов + их размещение
```

**Правило 1 страница = 1 primary keyword + 3-5 secondary:**

| Страница | Primary | Secondary |
|----------|---------|-----------|
| Главная | timber frame терраса СПб | террасы веранды навесы, строительство террас |
| Террасы TF | timber frame терраса | фахверк терраса, деревянная терраса премиум |
| Технология | timber frame технология | что такое фахверк, клеёный брус терраса |
| О нас | строительство террас СПб | подрядчик террасы ЛО, мастер timber frame |
| Калькулятор | терраса под ключ цена СПб | калькулятор террасы, стоимость террасы |

### 4. Генерация JSON-LD
```
Вход: Тип страницы (Product, Article, FAQ, LocalBusiness)
Выход: JSON-LD скрипт для вставки в <head>
```

---

## Чеклист SEO для каждого текста

- [ ] Title tag: 50-60 символов, ключевое слово в начале
- [ ] Meta description: 150-160 символов, ключевое слово + CTA
- [ ] H1: один на странице, содержит primary keyword
- [ ] H2-H3: содержат secondary keywords (не все — естественно)
- [ ] Первый абзац: ключевое слово в первых 100 словах
- [ ] Alt-тексты: описательные, с ключевыми словами где уместно
- [ ] URL: короткий, с ключевым словом (kebab-case, кириллица ОК для Яндекса)
- [ ] Внутренние ссылки: ≥2 на другие страницы сайта
- [ ] Длина: ≥800 слов для статей, ≥300 для страниц продуктов
