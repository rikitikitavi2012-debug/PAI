# WordstatResearch — Workflow

> Сбор реальных частотностей из Yandex Wordstat API перед созданием контента.
> Статьи пишутся на основе данных, а не догадок.

---

## Зачем

Без Wordstat: ключевые слова подбираются «из головы» → статья может целиться в пустоту.
С Wordstat: знаем точные частотности → выбираем темы с трафиком, вшиваем реальные ключи.

---

## Входные данные

| Параметр | Обязательный | Описание |
|----------|-------------|----------|
| Базовые фразы | ✅ | 1-10 фраз для исследования |
| Регион | По умолчанию СПб (GeoID: 2) | Числовой ID региона Яндекс |

---

## API: Yandex Direct API v4 (Wordstat)

**Эндпоинт:** `https://api.direct.yandex.com/v4/json/`

**Токен:** Из Secrets Store (ключ `YANDEX_DIRECT_TOKEN`). Передаётся в поле `token` JSON-тела запроса.

### Шаг 1: Создать отчёт

```bash
curl -s -X POST 'https://api.direct.yandex.com/v4/json/' \
  -H 'Authorization: Bearer $YANDEX_DIRECT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "method": "CreateNewWordstatReport",
    "token": "$YANDEX_DIRECT_TOKEN",
    "param": {
      "Phrases": ["терраса спб", "timber frame терраса"],
      "GeoID": [2]
    }
  }'
```

**Ответ:** `{"data": 123456789}` — ID отчёта.

**Ограничения:**
- Максимум 10 фраз за запрос
- Максимум 5 отчётов одновременно
- Одна фраза = до 7 слов

### Шаг 2: Подождать 3-5 секунд

Отчёт генерируется асинхронно. Подождать 3-5 секунд перед запросом результата.

### Шаг 3: Получить отчёт

```bash
curl -s -X POST 'https://api.direct.yandex.com/v4/json/' \
  -H 'Authorization: Bearer $YANDEX_DIRECT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "method": "GetWordstatReport",
    "param": 123456789,
    "token": "$YANDEX_DIRECT_TOKEN"
  }'
```

**Ответ:** Для каждой фразы два массива:
- `SearchedWith` — фразы, которые искали вместе с вашей (прямые вхождения). **Это главные данные.**
- `SearchedAlso` — похожие запросы (ассоциации). Полезно для идей.

**Формат результата:**
```json
{
  "data": [{
    "Phrase": "терраса спб",
    "SearchedWith": [
      {"Phrase": "терраса спб", "Shows": 1648},
      {"Phrase": "терраса купить спб", "Shows": 288},
      {"Phrase": "терраса спб цена", "Shows": 181}
    ],
    "SearchedAlso": [...]
  }]
}
```

### Шаг 4: Удалить отчёт (ОБЯЗАТЕЛЬНО!)

```bash
curl -s -X POST 'https://api.direct.yandex.com/v4/json/' \
  -H 'Authorization: Bearer $YANDEX_DIRECT_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "method": "DeleteWordstatReport",
    "param": 123456789,
    "token": "$YANDEX_DIRECT_TOKEN"
  }'
```

**Всегда удалять отчёт после использования.** Лимит — 5 одновременных отчётов.

## Шаги выполнения

### 1. Собрать базовые фразы

Для темы статьи подготовить 3-7 вариаций:
- Прямой запрос: «терраса timber frame»
- С гео: «терраса спб», «терраса ленинградская область»
- С интентом: «терраса купить», «терраса цена», «терраса под ключ»
- Длиннохвостые: «деревянная терраса к дому цена»

### 2. Запросить Wordstat

Создать отчёт → подождать → получить → удалить.

### 3. Проанализировать результат

Из `SearchedWith` извлечь:

| Фраза | Показов/мес | Приоритет |
|-------|------------|-----------|
| терраса спб | 1648 | Primary keyword |
| терраса купить спб | 288 | H2 keyword |
| терраса спб цена | 181 | H2 keyword |
| террасы веранды спб | 161 | Secondary |

**Критерии приоритетов:**
- **Primary keyword** (для H1, title, meta): >500 показов/мес + высокий коммерческий интент
- **H2 keyword** (для подзаголовков): 100-500 показов/мес
- **Secondary** (для текста): 30-100 показов/мес
- **Long-tail** (для FAQ, подзаголовков): <30 показов, но точный интент

### 4. Сформировать Keyword Brief

Итоговый документ для передачи в WriteArticle:

```markdown
## Keyword Brief: [тема]
Дата сбора: [дата]
Регион: СПб (GeoID: 2)

### Primary keyword
- [фраза] — [N] показов/мес

### H2 keywords
- [фраза] — [N] показов/мес
- [фраза] — [N] показов/мес

### Secondary keywords
- [фраза] — [N] показов/мес
- [фраза] — [N] показов/мес

### Long-tail (FAQ/подзаголовки)
- [фраза] — [N] показов/мес

### Идеи из SearchedAlso
- [фраза] — [N] показов/мес (потенциальная тема для новой статьи)
```

---

## Интеграция с WriteArticle

Этот воркфлоу вызывается **автоматически** как Шаг 0 в WriteArticle.
Keyword Brief передаётся в Шаг 2 (Планирование структуры) для выбора ключевых слов.

**Без Keyword Brief статья НЕ ДОЛЖНА публиковаться** — это гейт качества.

## Ошибки и решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `{"data": null}` при GetWordstatReport | Отчёт ещё не готов | Подождать ещё 3-5 секунд, повторить |
| Error 52 (authorization) | Токен невалиден | Проверить Secrets Store |
| Error 506 (report limit) | >5 отчётов | Удалить старые: `GetWordstatReportList` → `DeleteWordstatReport` |
| Пустой SearchedWith | Нет данных по фразе | Попробовать синонимы или более общую фразу |
