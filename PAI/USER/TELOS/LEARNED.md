Мудрость, добытая практикой. Эти уроки направляют будущие решения.

## Жизненные уроки

### О работе
- **Делегирование — мультипликатор.** Делегирование задач специализированным агентам (Agent Zero) даёт параллельную обработку и более глубокий анализ, чем один агент.
- **Контекст — это всё.** Полный контекст (TELOS) для подчинённого агента мгновенно выравнивает его с миссией и целями, убирая необходимость повторных промптов.
- **Один фокус = прогресс, распыление = стагнация.** Три параллельных проекта = ни один не доведён до конца. RedTeam подтвердил: 3/8 агентов указали что один человек не потянет три трека одновременно.
- **MVP запускай до готовности.** Перфекционизм — враг прогресса. "Ещё не готов" = никогда не будет готов. Сделанное лучше идеального.
- **Межсезонье — золотое время.** 4 зимних месяца (декабрь-март) = единственное окно для больших проектов. Каждый час на вес золота. Максимизируй.

### Об отношениях
- **Не показывай козыри до переговоров.** Prisoner's dilemma: кто открывается первым — теряет leverage. Сначала закрепи IP, потом демонстрируй результат.
- **Доверие строится медленно, теряется мгновенно.** 10 хороших объектов = авторитет у заказчика. 1 провал — и начинай сначала. Работает везде: подрядчики, партнёры, коллеги.

### О здоровье
- **В межсезонье тело деградирует.** Сидячий кодинг после физического сезона на стройке = резкий перепад нагрузки. Нужна системность в тренировках, иначе к апрелю будешь разбит.

### О деньгах
- **Резерв = свобода.** 38% капитала в резерве — не трусость, а стратегия. Без подушки безопасности нет свободы рисковать в бизнесе и инвестициях.
- **Акции > железо.** Физическое оборудование теряет 60-70% стоимости за 3 года. Акции производителей (NVIDIA, Micron, AMD) выросли на 200-400% за тот же период. Инвестируй в производителя, а не в продукт.
- **Не клади всё в одну корзину.** 5 направлений вложений (земля, акции, крипто, cloud, резерв) лучше чем одно "верное". Диверсификация спасает от чёрных лебедей.

### Об успехе
- **Экспертизу нельзя купить, код — можно.** 10+ лет в стройке = защитный ров, который конкурент не скопирует. Код можно делегировать AI или купить. Доменное знание и отношения с клиентами — нельзя.
- **Сначала для себя, потом для рынка.** Собственный бизнес = лучший тест-стенд для продукта. Если инструмент не решает твою проблему — он не решит чужую.

### О неудачах
- **Гонка за технологиями — бессмысленна.** Новые фреймворки появляются еженедельно. Невозможно следить за всем. Фокус на том что работает сейчас, а не на том что обещают завтра.
- **Без юридической защиты IP — всё впустую.** RedTeam анализ (2026-02-20): демонстрация бота фирме без закрепления прав = подарок конкуренту. Сначала юрист, потом демо.

### О системах и AI
- **AI Agent Orchestra > один ассистент.** Переход от "человек + один AI" к "человек управляет командой AI-агентов" — качественный скачок. Navi (архитектор), Jules (async-исполнитель), Agent Zero (исследователь) работают параллельно. Один человек = команда из 3-4 разработчиков. Прораб не кладёт плитку сам — он организует тех кто кладёт. Та же модель работает с AI.
- **Async-агент = работа пока ты спишь.** Jules работает в облаке, находит баги и пишет фиксы без участия человека. Proactive scan + Scheduled Tasks = 24/7 maintenance. Утром — готовые PR на ревью.
- **API > UI для оркестрации.** Кнопки в UI — для людей. API — для агентов. Navi управляет Jules через REST API, минуя UI полностью. Патчи вытягиваются, ревьюятся и применяются программно.
- **Интеграция сильнее изоляции.** Связывание изолированных систем (через A2A, REST API, AGENTS.md) создаёт возможности, превышающие сумму компонентов.
- **Глобальная конфигурация.** Централизация конфигурации (`agent_zero.json` в `~/.config/PAI`) упрощает работу по всем проектам мгновенно.
- **TELOS — операционная система личности.** Структурированный контекст (миссии → цели → вызовы → стратегии) позволяет любому AI агенту мгновенно понять кто ты и что тебе нужно.
- **Тесты для хуков — сеть безопасности.** 61 тест / 9 сюит ловят регрессии при любых изменениях в хуках. Без тестов — менять хуки вслепую, с тестами — уверенность в каждом коммите.
- **Негативные выводы агентов перепроверяй лично.** Агент прочитал один файл (TELOS.md — шаблон) и заявил что TELOS пустой, хотя рядом лежали 22 файла с данными. "X не существует" — самый опасный вывод для делегирования.
- **Community contribution = двойная выгода.** Фиксы в своей системе → PRs в upstream → репутация + влияние на инструмент. Стратегия S7 окупается: 6 PRs за 2 недели, acknowledgment в release notes.
- **Данные без верификации — мусор.** RatingCapture 52% false-positive 5s: промпт с конфликтующими инструкциями ("5 = neutral" + "null = no signal") генерировал шум. Чистка данных важнее чем их накопление.

## Уроки, которые приходится учить заново

Знаю, но забываю:

1. **Не распыляйся** — один проект за раз. Каждый раз при появлении новой идеи хочется бросить текущее и переключиться. Не делай этого. (C3)
2. **MVP > идеал** — запускай до готовности. "Ещё чуть-чуть доделаю" = ещё месяц без результата. (W1)
3. **Не доверяй — проверяй.** Особенно собственные допущения. Особенно когда "очевидно" что всё работает. (W8)
4. **Директория ≠ один файл.** Перед выводом о состоянии чего-либо — сначала `ls`. TELOS.md шаблон ≠ весь TELOS. (Урок марта 2026)
