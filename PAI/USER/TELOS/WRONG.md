## Ошибочные убеждения и решения

### 2025: Массовая реклама без фокуса = результат

- **Что я думал:** Широкая реклама (Яндекс.Директ, массовые ключевые слова) принесёт заявки на строительные услуги.
- **Что произошло:** 1 закрытая нецелевая заявка. Бюджет слит впустую.
- **Почему ошибся:** Не определил узкую нишу. Конкурировал в массовом сегменте (6-25К/м2) где сотни игроков. Нет UTP, нет фокуса = шум в толпе.
- **Урок:** Узкая ниша (Timber Frame, 50-120К/м2) > массовый рынок. 5 целевых заявок > 50 нецелевых. Стратегия S6 — прямой результат этой ошибки.

### 2025-2026: Telegram-бот — правильный подход для Цифрового Прораба

- **Что я думал:** Telegram-бот — идеальный формат для инструмента прораба. Все уже в Telegram, порог входа минимальный.
- **Что произошло:** Ограничения TG (нет offline, нет камеры для фотофиксации, нет полноценного UI) делали инструмент неудобным. Прорабы на объектах часто без связи.
- **Почему ошибся:** Оптимизировал под "легко начать" вместо "удобно пользоваться". Не учёл реальные условия работы (стройка, пыль, перчатки, отсутствие связи).
- **Урок:** PWA с offline-first — правильный формат. G0 переведён на PWA (февраль 2026). Технология должна соответствовать условиям использования, а не удобству разработчика.

### 2026-02: Можно одновременно вести 3-4 проекта

- **Что я думал:** Параллельная работа над P0 (PWA) + P1 (сайт TF) + P3 (PAI) + другими проектами даёт больше результатов.
- **Что произошло:** RedTeam анализ (3/8 агентов): один человек не потянет три трека. W5 нарушен. Ни один проект не завершён за межсезонье.
- **Почему ошибся:** Путал "активность" с "прогрессом". Переключение контекста между проектами = потеря 30-40% продуктивности. Compound effect требует фокуса.
- **Урок:** W5 ("Один проект за раз") существует не просто так. Осознанное нарушение W5 допустимо только при чётком двухфазном плане (S6 → сайт TF, потом G0 → PWA).

### 2026-02: AI заменяет, а не усиливает

- **Что я думал:** AI (Claude, GPT) может полностью заменить ручную работу — написать код, провести анализ, принять решение.
- **Что произошло:** Agent прочитал TELOS.md (шаблон) и заявил что TELOS пустой, хотя рядом лежали 22 файла. RatingCapture давал 52% false-positive 5s. Негативные выводы агентов без перепроверки = мусорные данные.
- **Почему ошибся:** MO10 (AI = рычаг) не означает "AI = замена". AI усиливает, но не заменяет критическое мышление и верификацию.
- **Урок:** "Перепроверяй агентов" (LEARNED). "Данные без верификации — мусор" (LEARNED). AI = рычаг для эксперта, не замена эксперту.

## Паттерны ошибок

| Тип ошибки | Пример | Частота | Митигация |
|------------|--------|---------|-----------|
| Оптимизм по времени | 4 проекта за межсезонье | Часто | W5 + двухфазный план |
| Широкий фокус | Массовая реклама | Средне | S6 узкая ниша |
| Технология ради технологии | TG бот вместо PWA | Редко | Проверять на реальных условиях |
| Доверие без верификации | AI-агент "всё пусто" | Средне | Перепроверять критические выводы лично |
