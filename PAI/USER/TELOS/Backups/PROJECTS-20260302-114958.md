## Активные проекты

### P0: PAI + TELOS (Личная AI-инфраструктура)
**Статус:** Активен, непрерывный
**Суть:** Мета-проект и фундамент для всего остального. PAI как фреймворк агентской инфраструктуры. TELOS как живой текстовый контекст — растёт, изменяется, совершенствуется вместе с нами. Navi как AI-партнёр, который учится и становится лучше с каждой сессией. Контекст — это актив: его можно переносить, хранить, накапливать для цифровой идентичности.
**Цель:** Полноценная личная операционная система: TELOS 22/22, PAI настроен, агенты работают, контекст глубокий.
**Срок:** Непрерывный процесс — система эволюционирует постоянно
**Подпроекты:**
- **PAI Dashboard** — Next.js UI для управления TELOS и PAI (5 страниц, 11 API)
- **TELOS заполнение** — эволюция контекста (20/22 файлов заполнено)
- **PAI инфраструктура** — скиллы, хуки, агенты, воркфлоу
**Результаты Research (2026-02-27):**
- Extensive Research: Context engineering оформился как дисциплина. PAI опережает академические Memory OS. Сохранено: `MEMORY/RESEARCH/2026-02/2026-02-27_context-engineering-personal-ai/`
- Research skill боевой тест: все 4 режима (Quick/Standard/Extensive/Deep) работают корректно
- Telos skill аудит: 9 багов пофикшено (плейсхолдеры, phantom refs, broken paths)
- Agent system аудит: 10 коммитов, 40+ phantom refs исправлено
