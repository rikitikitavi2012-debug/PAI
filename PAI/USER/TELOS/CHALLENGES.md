## Активные проблемы

### C0: Нехватка навыков (широкий фронт)
**Влияние:** Нужно одновременно осваивать: программирование (TypeScript, Python), AI/LLM (промпты, агенты, fine-tuning), бизнес (маркетинг, продажи), SketchUp для МАФ, крипту/DeFi. Невозможно стать экспертом во всём — приходится выбирать что учить первым.
**Основная причина:** Переход из строительной ниши в tech/AI требует совершенно нового набора навыков. Профессия прораба не готовила к вайбкодингу и контекстной инженерии.
**Связанные стратегии:** S0 (Learn-by-doing), S1 (AI-автоматизация — агенты компенсируют нехватку навыков)
**Статус:** Активно работаю. Межсезонье (декабрь-март) — основное время для обучения.
**Частично решено (март 2026):**
- **TF domain** — knowledge base мирового уровня (7 файлов, 15 мастеров, 12 соединений, стандарты). Экспертность по ремеслу timber frame теперь превышает уровень любого конкурента в РФ.
- **Landscaping domain** — 10+ лет опыта оцифрованы в 5 LS файлов (дренаж, бетон, мощение, земляные, климат СПб) + ANALYSIS.md из 53 реальных КП. Navi теперь может обсуждать грунты, расценки и нормативы на уровне прораба.
- **Бизнес-идентичность** — COMPANY.md + BRAND.md формализованы: команда, тон, палитра, ЦА, позиционирование.
Следующий шаг: практическое применение — /blagoustrojstvo на сайте, prices.json, первые КП.

### C1: Критический дефицит времени
**Влияние:** В сезон (апрель-ноябрь) работа 6/1, с 7:00 до 20:00. На свои проекты остаются вечера, выходные и паузы на объекте. В межсезонье (декабрь-март) — полная свобода, но 4 месяца недостаточно для масштабных проектов.
**Основная причина:** Финансовая зависимость от найма (M0 ещё не достигнута). Уйти с работы нельзя — нет альтернативного дохода.
**Окна возможностей:**
- Межсезонье (декабрь-март) — золотое время для разработки
- Вечера после объекта (19:00-22:00)
- Паузы на объекте (когда бригада работает автономно) — нужен планшет/ноутбук + интернет
- Выходные (1 день в неделю в сезон)
**Связанные стратегии:** S1 (AI-автоматизация), S2 (ступенчатый рост)
**Статус:** Управляемый. PAI система помогает максимизировать продуктивность в ограниченное время.

### C2: Технологическая изоляция РФ
**Влияние:** Блокировки нарастают. Доступ к OpenAI/Anthropic API через прокси. Оплата зарубежных сервисов — через посредников (зарубежные карты). Доступ к фондовому рынку (зарубежные акции) — ограничен. Ситуация будет только ухудшаться.
**Основная причина:** Государственная политика РФ: ужесточение блокировок, белые списки, ползучая изоляция от глобального интернета.
**Конкретные проблемы:**
- API OpenAI/Anthropic → обход через VPS NL (Timeweb)
- Оплата → посредники для зарубежных карт
- Биржа → нужно исследовать Interactive Brokers, Freedom Finance
- Тренд → блокировки усиливаются, нужна автономная инфраструктура
**Связанные стратегии:** S2 (ступенчатый рост), S3 (инфраструктурная независимость), S4 (диверсификация капитала)
**Статус:** В основном решено. VPS NL работает. Claude Code + Gemini CLI — через SSH-туннель + privoxy (Амстердам). Z.AI (GLM-5) — прямой доступ без прокси (китайская компания). Три AI-провайдера (Anthropic + Google + Zhipu AI) = тройное резервирование. Нужно: Venice AI через A0T, доступ к бирже.

### C3: Внутренние барьеры (перфекционизм + разбрасывание + нет плана)
**Влияние:** Три связанных проблемы:
1. **Перфекционизм** — делаю идеально вместо "достаточно хорошо". MVP не запускается, потому что "ещё не готов".
2. **Разбрасывание** — много проектов одновременно (Цифровой Прораб + МАФ сайт + PAI + крипта + земля). Энергия распыляется.
3. **Сложно начать без плана** — нужна чёткая структура перед действием. Парализует неопределённость.
**Основная причина:** Строительный бэкграунд: прораб привык к чёткому плану работ (смета → материалы → бригада → контроль). В tech/AI всё неопределённо — нет "проекта" в строительном смысле.
**Противоядие:** MVP > Perfect. Один проект за раз. TELOS = план. PAI = структура.
**Связанные стратегии:** S0 (learn-by-doing — начинай, разберёшься по ходу), TELOS (структура для планирования)
**Статус:** Осознаю проблему. TELOS помогает структурировать.

### C4: Скорость изменений (гонка за технологиями)
**Влияние:** AI-инструменты, агентские фреймворки, PAI, новые модели — всё меняется быстрее, чем успеваешь освоить. Только настроил одно — появилось новое. Ощущение вечной гонки.
**Основная причина:** AI-индустрия развивается экспоненциально. Новые модели каждый месяц. Новые фреймворки каждую неделю. Невозможно следить за всем.
**Связано с:** C0 (навыки), C1 (время)
**Связанные стратегии:** S1 (AI-автоматизация — агенты следят за обновлениями), PAIUpgrade skill
**Статус:** Постоянный. Принять как данность, фокусироваться на том что работает.
