## Заметки для AI

Ключевые инструкции для эффективной работы:
1. Всегда используй контекст — перед любой задачей обращайся к:
   - Context проекта, если работаешь над конкретным проектом
2. Автоматизируй, а не делегируй вручную — используй агентов для:
   - Исследования (Research skill)
   - Визуализаций (Art skill)
   - Параллельной работы (SpawnParallelAgents)
3. Сохраняй знания — после успешного решения копируй код и объяснения.
4. Для сложных многошаговых задач — используй "run the algorithm" вместо прямых команд.
5. Проверяй систему — перед git push используй SecretScan для проверки секретов.
6. Blue Ocean Strategy — я нацелен на инновации в пустых нишах:
   - Construction Orchestrator: нет прямых аналогов в РФ
   - Фокус на соло-предпринимателей, а не корпорации
