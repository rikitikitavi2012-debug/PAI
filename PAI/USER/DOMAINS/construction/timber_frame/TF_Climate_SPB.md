# TF Climate SPB — Адаптация Timber Frame к климату Петербурга

> Специфические решения для TF конструкций в условиях влажного морского климата СПб/ЛО.
> Источники: СП 131.13330, СП 20.13330, СП 64.13330, практический опыт.

---

## 1. Климатический профиль СПб/ЛО

| Параметр | Значение | Влияние на TF |
|----------|----------|---------------|
| Средняя влажность | 78% | Одна из самых высоких в РФ → гниение, плесень |
| Температурный диапазон | от -30°C до +35°C | Амплитуда 65°C → деформации, трещины |
| Осадки | ~660 мм/год | Защита узлов от прямого попадания |

| Снеговая нагрузка | III район: 180 кг/м² | Расчёт балок и стропил |
| Ветровая нагрузка | II район: 30 кгс/м² | Knee braces обязательны |
| Белые ночи (июнь) | UV до 16 ч/день | Ускоренное выгорание покрытий |

## 2. Критические узлы и решения

### 2.1. Контакт дерево → фундамент

**Проблема:** Капиллярный подсос влаги через бетон → гниение нижней обвязки.

```
НЕПРАВИЛЬНО:              ПРАВИЛЬНО:

  ┃ Стойка ┃               ┃ Стойка ┃
  ┃        ┃               ┃  (ель) ┃
  ┃        ┃               ┣━━━━━━━━┫ ← Подкладка лиственница 50мм
  ┣━━━━━━━━┫               ┣━━━━━━━━┫ ← Гидроизоляция (2 слоя)
  ┃ Бетон  ┃               ┃ Бетон  ┃ ← Высота цоколя ≥300 мм
  ┃        ┃               ┃        ┃
```

**Решение:**
1. Высота цоколя ≥ 300 мм (от грунта до дерева)
2. Гидроизоляция: 2 слоя рубероида или мембрана EPDM
3. Подкладная доска из лиственницы 50 мм (жертвенный элемент)
4. Вент. зазор 10-15 мм между подкладкой и стойкой
5. Обработка торцов Remmers Induline + восковой герметик

### 2.2. Открытые торцы балок

**Проблема:** Торцы впитывают влагу в 10-15 раз быстрее боковых поверхностей.

**Решение:**
1. Торцевой герметик (end sealer) — Anchorseal или Remmers Induline
2. Уклон верхних горизонтальных элементов ≥ 2% (от стены)
3. Капельники на выступающих торцах (drip edge)
4. Фаски 5-10 мм на всех ребрах (вода не скапливается)

### 2.3. Соединения

**Проблема:** Влага скапливается в пазах → гниение изнутри (невидимое).

**Решение:**
1. Дренажные канавки в дне паза (1-2 мм, для отвода конденсата)
2. Обработка внутренних поверхностей антисептиком ДО сборки
3. Draw-bore: обжатие соединения предотвращает попадание воды
4. Зазор дна паза 3-5 мм — для циркуляции воздуха

### 2.4. Террасный настил

**Проблема:** 50-70 циклов заморозки/оттаивания → расслоение, трещины.

**Решение:**
| Элемент | Требование | Почему |
|---------|-----------|--------|
| Зазор между досками | 5-8 мм | Вентиляция, отвод воды |
| Подконструкция | Лаги с уклоном 1-2% | Сток воды |
| Высота от грунта | ≥ 200 мм | Вентиляция снизу |
| Крепёж | Нержавеющая сталь A4 | Обычная ржавеет за 2-3 года |
| Антискользящий профиль | Вельвет | Безопасность при обледенении |

## 3. Сезонный уход (для контента)

### Весна (март-апрель)
- Осмотр всех соединений после зимы
- Очистка от мха и лишайника (щётка + Neomid BioCleaner)
- Проверка торцов на трещины
- Обновление масла на настиле (если нужно)

### Лето (июнь-август)
- Проверка покрытия каркаса (UV деградация)
- Подтяжка ослабших нагелей (если есть)
- Осмотр гидроизоляции фундамент↔дерево

### Осень (сентябрь-октябрь)
- Очистка водоотводных каналов
- Обработка проблемных зон антисептиком перед зимой
- Проверка снегозадержателей (если есть крыша)

### Зима
- Снеговая нагрузка: не допускать >250 кг/м² (убирать при >30 см мокрого снега)
- Не скалывать лёд с настила металлическим инструментом
