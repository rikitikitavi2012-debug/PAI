# TF Engineering — Инженерные расчёты Timber Frame

> Мост между российскими СП и международными TF-стандартами (TFEC, Eurocode 5).
> Источники: TFEC 1-2019, Eurocode 5 (EN 1995), СП 64.13330.2017, "A Timber Framer's Workshop" (Chappell).

## 1. Расчёт соединения Mortise & Tenon

### Геометрические правила (TFEC + Chappell)

Для бруса сечением **b × h** (ширина × высота):

| Параметр | Правило | Пример (200×200 мм) |
|----------|---------|---------------------|
| Ширина шипа (tenon) | 1/3 ширины бруса | 66 мм (~65 мм) |
| Высота шипа | ≤ 3/4 высоты бруса | ≤ 150 мм |
| Глубина паза (mortise) | = ширина шипа + 3 мм зазор | 68 мм |
| Минимальная щека паза | ≥ 1/4 ширины бруса | ≥ 50 мм |
| Расстояние до края | ≥ 2d (d = диаметр нагеля) | ≥ 50 мм (при d=25) |
| Нагель (peg) | ∅20-25 мм, из дуба или берёзы | ∅25 мм |
| Draw-bore offset | 3 мм (шип) относительно гнезда | 3 мм |

### Нагрузка на Mortise & Tenon

**По TFEC 1-2019, раздел 4.6:**

```
Несущая способность на срез:
  T_shear = A_tenon × R_shear × k_mod

Где:
  A_tenon = ширина_шипа × высота_шипа (площадь сечения шипа)
  R_shear = расчётное сопротивление срезу (1.2 МПа — сосна/ель 2 сорт по СП 64)
  k_mod = коэффициент условий (0.85 для класса 2 — открытые террасы)
```

**Пример: Шип 65×150 мм (брус 200×200, сосна 2 сорт):**
```
A_tenon = 65 × 150 = 9750 мм² = 97.5 см²
T_shear = 97.5 × 1.2 × 0.85 = 99.5 кН ≈ 10 тонн на срез
```

> **Для контента:** "Одно соединение шип-паз в брусе 200×200 выдерживает до 10 тонн на срез — это вес 2 легковых автомобилей."

### Нагрузка на Dovetail

```
Несущая способность определяется:
  1. Сопротивлением смятию поперёк волокон (R_cm90 = 1.8 МПа по СП 64)
  2. Углом ласточкина хвоста (типично 1:6 — 1:8, угол ~7-9°)
  3. Глубиной посадки

Преимущество: самоблокирующееся — нагрузка УВЕЛИЧИВАЕТ прочность
Недостаток: требует точной подгонки (допуск ±0.5 мм)
```

## 2. Расчёт каркаса Bent Frame

### Типичная рама (bent) для террасы

```
Схема (вид спереди):

    ┌──────────────────────────────────┐  ← Верхняя балка (girt/plate) 200×200
    │              ╱    ╲              │
    │    knee   ╱          ╲   knee    │  ← Подкосы (knee braces) 150×150
    │    brace╱              ╲brace   │
    │       ╱                  ╲       │
    ├──────┤                    ├──────┤
    │      │                    │      │
    │      │     Стойки         │      │  ← Стойки (posts) 200×200
    │      │     (posts)        │      │
    │      │                    │      │
    └──────┘                    └──────┘
    ▓▓▓▓▓▓▓▓                    ▓▓▓▓▓▓▓▓  ← Фундамент (piers)

    ←──────── Пролёт 3-5 м ─────────→
```

### Расчёт верхней балки (по СП 64 + TFEC)

```
Исходные данные (терраса с крышей, СПб):
  Пролёт L = 4 м
  Шаг рам = 2 м
  Нагрузка (крыша + снег): q = 180 (снег III район) + 50 (собственный вес) = 230 кг/м²
  Грузовая площадь на балку: 4 × 2 = 8 м²
  Линейная нагрузка: q_lin = 230 × 2 = 460 кг/м = 4.6 кН/м

Проверка на изгиб (балка 200×200 мм, клеёный брус GL24h):
  M = q × L² / 8 = 4.6 × 4² / 8 = 9.2 кН·м
  W = b × h² / 6 = 200 × 200² / 6 = 1 333 333 мм³ = 1333 см³
  σ = M / W = 9.2 × 10⁶ / 1 333 333 = 6.9 МПа
  R_изг (GL24h) = 24 МПа × k_mod(0.85) = 20.4 МПа

  6.9 МПа < 20.4 МПа → ЗАПАС ×3 ✓

Проверка на прогиб:
  f = 5 × q × L⁴ / (384 × E × I)
  E (GL24h) = 11 600 МПа
  I = b × h³ / 12 = 200 × 200³ / 12 = 133 333 333 мм⁴
  f = 5 × 4.6 × 4000⁴ / (384 × 11600 × 133 333 333) = 9.9 мм
  f_допуст = L / 250 = 4000 / 250 = 16 мм

  9.9 мм < 16 мм → ПРОГИБ в норме ✓
```

> **Для контента:** "Балка 200×200 из клеёного бруса GL24h перекрывает 4 метра с тройным запасом прочности. В обычном каркаснике для этого нужна двутавровая балка или ферма."

### Подкосы (Knee Braces) — расчёт

```
Knee brace работает на сжатие. По TFEC:
  Минимальное сечение: 100×100 мм (рекомендуемое: 150×150 мм)
  Угол: 45° ± 15° (оптимально 45°)
  Длина: определяется геометрией (при 45° и высоте 600 мм → L = 850 мм)

Соединение knee brace к стойке и балке:
  Тип: mortise & tenon (чаще housing joint)
  Фиксация: 1 нагель ∅25 мм на каждом конце
  Прочность на сжатие (150×150, сосна 2 сорт):
    N_допуст = A × R_с = 22500 × 13 = 292 500 Н ≈ 30 тонн

Ветровая нагрузка (СПб, II район):
  q_ветр = 30 кгс/м² = 0.3 кН/м²
  На раму (высота 3м, шаг 2м): F = 0.3 × 3 × 2 = 1.8 кН
  Knee brace выдерживает 292 кН → запас ×160 ✓
```

## 3. Мост TFEC → СП 64

### Что покрывает СП 64 для TF

| Раздел СП 64 | Применимость к TF | Примечание |
|---|---|---|
| п. 6.3 — Сорт древесины | ✅ Полностью | Не ниже 2-го сорта для несущих |
| п. 6.7.4 — Влажность | ✅ Полностью | ≤20% для наружных (клеёный = 8-12%) |
| табл. Е.1 — Расчётные сопротивления | ✅ Полностью | R_изг, R_сж, R_см, R_ск |
| Раздел 8 — Соединения | ⚠️ Частично | Болты, нагели, гвозди — НО нет M&T, dovetail |
| Раздел 10 — Защита | ✅ Полностью | Антисептирование, огнезащита |
| Раздел 9 — Клеёные | ✅ Полностью | GL24h-GL28h |

### Что НЕ покрывает СП 64 (нужен TFEC)

| Тема | Почему СП 64 недостаточен | Где брать |
|---|---|---|
| Mortise & Tenon расчёт | СП 64 не знает столярных соединений | TFEC 1-2019, раздел 4.6 |
| Knee brace проектирование | Нет требований к подкосам TF | TFEC 1-2019, раздел 5 |
| Raising (подъём каркаса) | Нет описания монтажа TF | TFEC 2-2018 |
| Допуски столярных соединений | СП 64 = допуски для болтов/гвоздей | TFEC 2-2018, раздел 6 (±1.5 мм) |
| SIP заполнение стен | Не-несущие стены в TF | TFEC 1-2019, раздел 7 |

### Практическое применение для нас

```
При проектировании TF террасы/веранды:
1. Нагрузки → по СП 20.13330 (снег, ветер, полезная)
2. Расчёт балок и стоек → по СП 64 (R, E, допуски прогиба)
3. Расчёт соединений → по TFEC (M&T, dovetail, knee brace)
4. Клеёный брус → по ГОСТ 20850 (GL24h класс)
5. Защита → по СП 64 раздел 10 + ГОСТ Р 53292
```

## 4. Коэффициенты и поправки

### Коэффициенты модификации (k_mod) по Eurocode 5

| Класс службы | Описание | k_mod (средняя длительность) |
|---|---|---|
| 1 | Закрытое, отапливаемое | 0.80 |
| 2 | Навес, открытая веранда, терраса | 0.80 |
| 3 | Контакт с грунтом, погружённые | 0.65 |

### Частный коэффициент материала (γ_M) по Eurocode 5

| Материал | γ_M |
|---|---|
| Цельная древесина | 1.3 |
| Клеёный брус (glulam) | 1.25 |
| Соединения | 1.3 |

> **Расчётное сопротивление по Eurocode 5:**
> `f_d = k_mod × f_k / γ_M`
> Пример GL24h изгиб: f_d = 0.80 × 24 / 1.25 = 15.4 МПа

## 5. Типовые ошибки проектирования TF

### Flaw ID: TF_UNDERSIZED_TENON
**Описание:** Шип тоньше 1/3 ширины бруса — откалывание щёк.
**Риск:** Разрушение соединения при нагрузке на 40-60% ниже расчётной.
**Как правильно:** Шип = 1/3 ширины бруса ± 3 мм.

### Flaw ID: TF_NO_DRAW_BORE
**Описание:** Отверстия под нагель в шипе и пазе совпадают точно.
**Риск:** Соединение не обжимается, может разболтаться за 3-5 лет.
**Как правильно:** Draw-bore offset 3 мм — при забивании нагеля шип подтягивается.

### Flaw ID: TF_WRONG_DOVETAIL_ANGLE
**Описание:** Угол ласточкина хвоста слишком крутой (>1:5) или пологий (<1:8).
**Риск:** >1:5 — откалывание; <1:8 — не самоблокируется.
**Как правильно:** Угол 1:6 — 1:8 (≈7-9.5°).

### Flaw ID: TF_KNEE_BRACE_TOO_SHORT
**Описание:** Подкос короче 600 мм — не создаёт эффективный треугольник.
**Риск:** Каркас раскачивается при ветровой нагрузке.
**Как правильно:** Минимум 600 мм по каждой стороне (длина ~850 мм при 45°).

### Flaw ID: TF_GRAIN_ORIENTATION
**Описание:** Шип нарезан поперёк волокон — вместо продольного.
**Риск:** Прочность на срез падает в 5-7 раз.
**Как правильно:** Шип ВСЕГДА вдоль волокон горизонтального элемента.

## 6. Трусовые системы — 5 базовых типов (YouTube extraction)

> Источник: Timber Frame HQ. Все TF фермы = вариации 5 базовых типов.

| # | Тип | Прочность | Стоимость | Нужен инженер? | Применение |
|---|-----|-----------|-----------|----------------|-----------|
| 1 | **Common Truss** | ★★★★★ | $ | Нет | Универсальный — максимум прочности за минимум денег |
| 2 | **Queen Post** | ★★★★ | $$ | Нет | Большие залы с окнами во фронтоне |
| 3 | **King Post** | ★★★★ | $$ | Нет | Гибридные проекты, комбинирование стилей |
| 4 | **Scissor Truss** | ★★★ | $$$ | Желательно | Сложные пролёты, высокие потолки |

> **Hammer beam — единственный тип, ОБЯЗАТЕЛЬНО требующий инженерного расчёта.**

## 7. Knee braces — инженерная реальность (YouTube extraction)

> Источник: Timber Frame Design & Build Channel (Bert). Канал между мастерами и инженерами.

### Факт: Knee braces УМЕНЬШАЮТ расчётный пролёт tie-beam

Но большинство инженеров **отказываются это учитывать** в расчёте.

### Причина — экономическая, не техническая:
```
Для учёта knee brace инженер ДОЛЖЕН дополнительно:
  1. Проверить прочность соединения brace↔beam
  2. Рассчитать изгиб стойки от боковой нагрузки (thrust)
  = Два дополнительных расчёта + повышенная ответственность
  → Большинство инженеров предпочитают "overdesign"
```

### Как убедить инженера:
1. **Крутой угол brace** → меньше горизонтальная нагрузка на стойку
2. **Привязка к фундаменту** → thrust уходит в бетон, не в стойку
3. **Аналогия с фермой** — инженеры хорошо понимают truss behavior
4. Подходить с позиции: "как мне облегчить вам валидацию?"

### Timberline Lodge — proof of concept
```
Oregon, 1930-е годы. Не проходит современный расчёт на бумаге.
Стоит десятилетия под снегом и ветром.
Вывод: реальная прочность TF > расчётная по стандартным моделям.
Причина: инженерные модели не могут учесть redundant load paths
и сложное поведение деревянных столярных соединений.
```

### Экономика knee braces
- Соотношение труд/материалы в TF: **2:1** (труд = 2× материалов)
- В стандартном каркаснике: **1:1**
- Overengineering = норма до тех пор пока "the market says enough"

## 8. Raising (подъём рамы) — практические данные (YouTube extraction)

> Источник: Two Guys Timberframing. Реальный подъём multi-story barn, 2 человека + crane.

### Временные бенчмарки
| Этап | Время | Примечание |
|------|-------|-----------|
| День 1 | Первые bents | Самый сложный — нет опорных точек |
| День 2-3 | Основные секции | С каждым bent проще |
| День 4 | Финальные секции | В пределах вылета крана |

### Критические правила
1. **Dry fit ВСЁ на столе** перед подъёмом — главный time-saver
2. **Пластиковый/деревянный молоток** — НИКОГДА стальной
3. **"Keep my toes clear"** — ноги из-под опускаемого бруса
4. **Escape route** — мысленная репетиция отхода ПЕРЕД каждым подъёмом
5. **$300 cheap lumber** для временных раскосов — не портить timber
6. **Собственный кран >> арендованный** — можно работать фазами

### Масштабное искажение (universal)
> "They were looking at it for months. I had no idea."
> Даже опытные мастера шокированы размером рамы при подъёме vs на столе.
