### Требования к клеёному брусу для TF

| Параметр | Требование | Стандарт |
|----------|-----------|----------|
| Влажность | 8-12% (камерная сушка) | ГОСТ 20850 п.5.2 |
| Класс клея | I (водостойкий) для наружных | ГОСТ 33122 |
| Усадка | ≤ 0.1% (vs 5-7% у массива) | — |
| Ламели | Толщина ≤ 40 мм каждая | ГОСТ 20850 п.5.3 |
| Порода | Ель, сосна (каркас); лиственница (контакт с водой) | — |
| Калибровка | ±1 мм по сечению | ГОСТ 20850 |
| Обработка | Антисептик + огнебиозащита (для открытых) | ГОСТ Р 53292 |

### Почему НЕ массив для TF

| Параметр | Клеёный брус | Массив (сосна) |
|----------|-------------|----------------|
| Усадка | 0.1% | 5-7% |
| Трещины | Нет (перекрёстные ламели) | Да (неизбежно) |
| Калибровка | ±1 мм | ±3-5 мм |
| R_изг | 24 МПа (GL24h) | 14 МПа (2 сорт) |
| Влажность | 8-12% (гарантировано) | 18-22% (если повезёт) |
| Цена за м³ | 45 000-65 000 ₽ | 15 000-25 000 ₽ |

> **Для контента:** "Да, клеёный брус в 3 раза дороже массива. Но через 2 года массив треснет и поведёт — а клеёный будет стоять как новый 50+ лет."

## 2. Нагели (Wooden Pegs)

### Характеристики

| Параметр | Значение |
|----------|----------|
| Порода | Дуб (предпочтительно) или берёза |
| Диаметр | ∅20 мм (для бруса ≤150) / ∅25 мм (для ≥200) |
| Влажность | 6-8% (суше основного бруса на 2-4%) |
| Направление волокон | Строго продольное (прямослой) |
| Форма | Цилиндрическая, с лёгким конусом на конце (1-2°) |
| Длина | Ширина стойки + 10-15 мм (для through tenon) |

### Почему дуб, а не берёза

```
Дуб:
  - Плотность 690 кг/м³ → держит нагрузку
  - Танины → натуральная защита от гниения
  - Не раскалывается при забивании

Берёза:
  - Плотность 650 кг/м³ → чуть слабее
  - Нет танинов → уязвима во влажной среде
  - Дешевле и доступнее

Вывод: дуб для наружных (террасы), берёза для внутренних (веранды)
```

| Параметр | Значение | Сравнение |
|----------|----------|-----------|
| Плотность | 660 кг/м³ | > дуба (630) |
