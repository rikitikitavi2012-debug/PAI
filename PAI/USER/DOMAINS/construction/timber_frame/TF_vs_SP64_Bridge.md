# TF vs SP64 Bridge — Мост между российскими нормами и TF-стандартами

> Какие пункты СП 64 применимы к Timber Frame, какие нет, где TFEC и Eurocode 5 дополняют.
> Цель: проектировать TF конструкции с опорой на российские нормы + мировые best practices.

---

## 1. Матрица применимости СП 64 к Timber Frame

### Полностью применимые разделы

| Раздел СП 64 | Пункт | Что покрывает | TF-контекст |
|---|---|---|---|
| Материалы | п. 6.1-6.3 | Сорта древесины (≥2-й для несущих) | Одинаково для TF и каркасника |
| Влажность | п. 6.7.4 | ≤20% для наружных конструкций | Клеёный брус = 8-12% (превышает) |
| Прочность | табл. Е.1 | R_изг, R_сж, R_см, R_ск | Базовые расчёты балок и стоек |
| Клеёные | Раздел 9 | GL20h-GL28h, требования к клею | Полностью для TF из клеёного |
| Защита | Раздел 10 | Антисептирование, огнезащита | Одинаково |
| Прогибы | табл. Л.1 | Предельные прогибы (l/250) | Одинаково |
| Нагрузки | → СП 20 | Снег, ветер, полезные | Одинаково |

### Частично применимые разделы

| Раздел СП 64 | Пункт | Проблема | Что делать |
|---|---|---|---|
| Соединения | Раздел 8 | Описаны только: болты, нагели, гвозди, клей. **Нет M&T, dovetail, scarf** | Дополнять TFEC 1-2019 раздел 4 |
| Конструктивные требования | Раздел 7 | Ориентирован на стойки+обшивка (каркасник), не на bent frame | Дополнять TFEC 1-2019 раздел 5 |
| Допуски | — | Допуски для промышленных соединений (±3-5 мм) | TF требует ±1-1.5 мм (TFEC 2-2018) |

### НЕ применимые (нужен TFEC / Eurocode 5)

| Тема | Почему СП 64 не работает | Источник |
|---|---|---|
| Расчёт M&T | Нет формул для столярных соединений | TFEC 1-2019, раздел 4.6 |
| Knee brace проектирование | Нет понятия "подкос в TF" | TFEC 1-2019, раздел 5.3 |
| Bent frame как система | Нет понятия "рама" в TF смысле | TFEC 1-2019, раздел 3 |
| Raising (подъём рамы) | Нет монтажных требований для TF | TFEC 2-2018, раздел 8 |
| SIP-панели как заполнение | Нет в СП 64 | TFEC 1-2019, раздел 7 |
| Dovetail расчёт | Нет | Eurocode 5, Annex |

## 2. Алгоритм проектирования TF по двум стандартам

```
ЭТАП 1: Нагрузки (100% СП 20.13330)
  → Снег (III район СПб = 180 кг/м²)
  → Ветер (II район = 30 кгс/м²)
  → Полезная (террасы = 400 кг/м², жилые = 150 кг/м²)
  → Собственный вес (расчёт по массе элементов)

ЭТАП 2: Расчёт элементов (80% СП 64 + 20% TFEC)
  → Балки: прочность + прогиб по СП 64
  → Стойки: устойчивость по СП 64
  → Клеёный брус: GL-класс по ГОСТ 20850
  → Сечения: подбор по таблицам СП 64

ЭТАП 3: Расчёт соединений (100% TFEC + Eurocode 5)
  → M&T: размеры шипа, нагрузка на срез (TFEC 4.6)
  → Dovetail: углы, глубина посадки
  → Knee braces: сечение, длина, угол (TFEC 5.3)
  → Нагели: диаметр, расстояния, draw-bore

ЭТАП 4: Допуски (100% TFEC 2-2018)
  → Шип-паз: ±1.0 мм
  → Длина элемента: ±3-5 мм
  → Положение паза: ±1.5 мм

ЭТАП 5: Защита (100% СП 64 + ГОСТ Р 53292)
  → Антисептик
  → Огнебиозащита (класс по ГОСТ)
  → Покрытие (Osmo/Remmers/Teknos)

ЭТАП 6: Монтаж (100% TFEC 2-2018)
  → Сборка рам (bents) горизонтально
  → Raising: подъём рам (ручной/кран)
  → Соединение рам прогонами
  → Установка knee braces
  → Проверка вертикальности (отвес, уровень)
```

## 3. Сравнение параметров: СП 64 vs TFEC vs Eurocode 5

### Расчётные сопротивления

| Параметр | СП 64 (сосна 2с) | TFEC (SYP #2) | Eurocode 5 (C24) |
|----------|------------------|---------------|-------------------|
| R_изг | 14 МПа | 10.3 МПа (1500 psi) | 24 МПа (f_k) / γ_M |
| R_сж | 13 МПа | 7.6 МПа (1100 psi) | 21 МПа (f_k) / γ_M |
| R_ск (срез) | 1.2 МПа | 1.2 МПа (180 psi) | 4.0 МПа (f_k) / γ_M |
| E (модуль) | 10 000 МПа | 11 000 МПа | 11 000 МПа |

> **Примечание:** Различия из-за разных методов испытаний и коэффициентов безопасности. При проектировании в РФ → используем СП 64 (обязательный). TFEC/Eurocode 5 — для соединений и конструктивных решений.

### Коэффициенты безопасности

| Стандарт | Коэффициент | Значение | Примечание |
|----------|-------------|----------|------------|
| СП 64 | γ_f (нагрузки) | 1.1-1.4 | По типу нагрузки |
| СП 64 | m_дл (длительность) | 0.8 | Для снега |
| Eurocode 5 | γ_M (материал) | 1.25-1.3 | Glulam / solid |
| Eurocode 5 | k_mod (условия) | 0.65-0.80 | По классу службы |
| TFEC | Safety factor | 2.5-3.0 | Для соединений |

## 4. Юридический аспект

### Что обязательно в РФ

```
При строительстве террас/веранд/навесов (до 2 этажей, S < 1500 м²):
  ✅ Обязательно: СП 64.13330 (деревянные конструкции)
  ✅ Обязательно: СП 20.13330 (нагрузки)
  ✅ Обязательно: ГОСТ 20850 (если клеёный брус)
  ⚠️ Рекомендательно: СП 17 (кровли), СП 22 (фундаменты)

  ❌ TFEC / Eurocode 5 — НЕ имеют юридической силы в РФ
  ✅ НО: можно ссылаться как на "лучшие мировые практики"
```

### Как подавать в контенте

```
"Мы проектируем по российским нормам (СП 64, ГОСТ 20850) — это обязательный
минимум. Но для соединений используем стандарты Timber Framers Guild (TFEC) —
единственный в мире инженерный стандарт, созданный специально для timber frame.
Это как строить по ГОСТ + добавить лучшие практики из Германии и Америки."
```

> **W10:** Глубина экспертизы = конкурентный ров. Конкуренты знают СП 64. Мы знаем СП 64 + TFEC + Eurocode 5. Разница = доверие клиента.

## 5. Чек-лист проектирования TF (для внутреннего использования)

### До начала проектирования
- [ ] Определён тип конструкции (bent frame / post-and-beam / фахверк)
- [ ] Собраны нагрузки по СП 20 (снег, ветер, полезная)
- [ ] Выбран класс клеёного бруса (GL24h стандарт, GL28h премиум)
- [ ] Определены сечения стоек и балок (расчёт по СП 64)

### Соединения (по TFEC)
- [ ] Шип-паз: ширина = 1/3 b, щека ≥ 1/4 b
- [ ] Нагели: дуб ∅25 мм, draw-bore 3 мм
- [ ] Knee braces: 150×150, угол 45°, длина ≥ 600 мм
- [ ] Допуски размечены: ±1.0 мм на шип, ±1.5 мм на позицию

### Защита (СП 64 + практика СПб)
- [ ] Гидроизоляция фундамент↔дерево: 2 слоя
- [ ] Подкладка лиственница 50 мм
- [ ] Торцы загерметизированы (Anchorseal)
- [ ] Покрытие каркаса (Osmo/Remmers)
- [ ] Вент. зазоры обеспечены

### Документация
- [ ] 3D-модель (SketchUp от Шульца)
- [ ] Спецификация материалов (BOM)
- [ ] Фиксированная смета
