# LS Climate SPB -- Климат СПб и благоустройство

> Специфика климата Санкт-Петербурга и Ленинградской области для ландшафтных
> и благоустроительных работ: грунты, промерзание, водоотведение, сезонность.
> Источники: СП 131.13330.2020, СП 22.13330, данные Росгидромет, практический опыт.

## 1. Климатический профиль СПб/ЛО

| Параметр | Значение | Влияние на благоустройство |
|----------|----------|---------------------------|

| Средняя t июля | +18..+20C | Короткое окно для бетонных работ |
| Температурная амплитуда | ~60C | Разрушение покрытий, деформации швов |

## 2. Глубина промерзания по типам грунта

> Источник: СП 22.13330, таблица 5.3, нормативные значения для СПб.

| Тип грунта | d_fn, м | Распространённость в ЛО | Пучинистость |
|------------|---------|-------------------------|--------------|
| Глина | 1.1 | 30% территории | Сильнопучинистый |
| Суглинок | 1.3 | 35% территории | Пучинистый |
| Супесь | 1.4 | 15% территории | Среднепучинистый |
| Песок мелкий | 1.5 | 10% территории | Слабопучинистый |
| Крупнообломочный | 1.7 | 10% территории | Непучинистый |

### Расчётная глубина промерзания

```
d_f = d_fn * k_h

d_fn -- нормативная глубина (таблица выше)
k_h  -- коэффициент теплового влияния сооружения

Значения k_h:
  Отапливаемое здание, t >= +20C:  k_h = 0.5-0.7
  Неотапливаемое / открытый грунт: k_h = 1.0-1.1
  Под отмосткой с утеплителем ЭППС: k_h = 0.6-0.8
```

**Практическое правило:** Дренаж и ливневку закладывать на глубину не менее d_fn + 200 мм запаса. Для глины СПб = минимум 1.3 м.

## 3. Морозное пучение

### Механизм

Вода в порах грунта замерзает (расширение 9%) --> грунт поднимается на 50-150 мм -->
весной оттаивание неравномерное --> перекос плитки, трещины бетона, наклон столбов.

### Пучинистые грунты ЛО (до 80% территории!)

| Категория | Грунт | Подъём поверхности | Опасность |
|-----------|-------|--------------------|-----------|
| Сильнопучинистый | Глина, суглинок пылеватый | 70-150 мм | Критическая |
| Пучинистый | Суглинок, супесь пылеватая | 35-70 мм | Высокая |
| Слабопучинистый | Песок мелкий, супесь | 10-35 мм | Средняя |
| Непучинистый | Щебень, крупный песок, ПГС | <10 мм | Низкая |

### Схема: пучение под мощением

```
БЕЗ ПОДГОТОВКИ:                 С ПРАВИЛЬНЫМ ОСНОВАНИЕМ:

  ~~плитка~~     /плитка\          ═══плитка═══════
  ~~песок~~    /   песок  \        ---песок 30мм---
  ##глина##  ## ПУЧЕНИЕ ##        ===щебень 200мм===
                                  ///геотекстиль///
  Подъём 50-100 мм               ===ПГС 200мм=====
  Плитка перекошена               ///геотекстиль///
                                  ---грунт---------
                                  Подъём <10 мм
```

### Меры против пучения

1. **Замена грунта** -- выемка пучинистого, засыпка щебнем/ПГС на глубину 400-600 мм
2. **Дренаж** -- снижение УГВ = меньше воды = меньше пучения
3. **Утеплитель ЭППС** -- под отмосткой и площадками (50-100 мм, L-блок у фундамента)
4. **Песчаная подушка** -- минимум 200 мм крупного песка под любое мощение

## 4. Уровень грунтовых вод (УГВ)

### Типичные значения для СПб/ЛО

| Зона | УГВ | Характеристика |
|------|-----|---------------|
| Низины, поймы рек | 0.3-0.5 м | Критически высокий, болотистость |
| Равнины, Приморский район | 0.5-1.0 м | Высокий, дренаж обязателен |
| Пологие склоны | 1.0-1.5 м | Средний, дренаж рекомендован |
| Возвышенности, Карельский перешеек | 1.5-3.0 м | Низкий, дренаж ситуативно |

### Сезонная динамика

```
УГВ  J  F  M  A  M  J  J  A  S  O  N  D
0.3м          ##                   ##
0.7м       ######               ######
1.0м    ############      ############
1.3м  ########################################
      зима  весна  лето   лето  осень  зима
            МАКС          мин   МАКС
```

**Максимум:** апрель (таяние) и октябрь (дожди). **Минимум:** июль-август и январь-февраль.

**Замер:** шурф 1.5-2.0 м --> ждать 24-48 ч --> замерить. Делать в апреле (максимум УГВ).
**Правило:** При УГВ < 1.5 м -- дренажная система обязательна.

## 5. Сезонный календарь работ

| Месяц | Работы | Условия | Ограничения |
|-------|--------|---------|-------------|
| Март | Оценка участка, планирование, заказ материалов | Грунт мёрзлый, снег тает | Земляные работы невозможны |
| Апрель | Расчистка, начало земляных (2-я половина) | Грунт оттаивает, УГВ макс | Техника вязнет, глина мокрая |
| Май | Земляные, дренаж, ливневка, фундаменты | Грунт подсох, t +8..+15C | Оптимально для земляных |
| Июнь | Бетонные работы, начало мощения | Длинный день (19 ч), t +15..+20C | Пик оптимальности |
| Июль | Мощение, бетон, комплексные проекты | Пик сезона, t +18..+25C | Заказы: очередь 2-4 недели |
| Август | Мощение, подпорные стены, газон (посев) | Пик, t +16..+22C | Материалы на складе заканчиваются |
| Сентябрь | Газон (последний срок посевной), парковки, отмостки | Укороченный день, t +10..+15C | Дожди, бетон сохнет медленнее |
| Октябрь | Финишные работы, консервация | Дожди, t +3..+8C | Бетон только с противоморозными |
| Ноябрь | Мелкие доделки, уборка | Первые заморозки | Конец сезона, земляные невозможны |

**Критично:** Эффективный сезон = 4-5 месяцев (май-сентябрь). Планировать и заказывать в марте-апреле.

## 6. Водный баланс участка

**Баланс:** (осадки + сток соседей + грунтовые) - (дренаж + ливневка + испарение + инфильтрация) = 0.
Если приход > расход --> подтопление участка.

### Расчётные параметры для СПб

| Параметр | Значение | Примечание |
|----------|----------|-----------|
| q20 (интенсивность 20-мин дождя) | 80 л/(с*га) | Для расчёта ливневки |
| q5 (интенсивность 5-мин дождя) | 130 л/(с*га) | Пиковый ливень |
| Период повторяемости (благоустройство) | 1 год | P = 1, стандарт |
| Период повторяемости (здания, парковки) | 10 лет | P = 0.1, усиленный |
| Коэффициент стока: плитка | 0.6 | 60% воды уходит в ливневку |
| Коэффициент стока: бетон/асфальт | 0.85-0.95 | Почти весь объём |
| Коэффициент стока: газон | 0.1-0.3 | Основная инфильтрация |
| Коэффициент стока: щебень | 0.3-0.4 | Частичная инфильтрация |

### Пример: участок 10 соток (1000 м2)

```
Мощение 300м2*0.6 + Бетон 100м2*0.9 + Газон 500м2*0.2 + Щебень 100м2*0.35 = 405 м2
Q = 405 * 80 / 10000 = 3.24 л/с --> Труба D110 (~5 л/с) достаточно, 4+ дождеприёмника
```

## 8. Рекомендации по материалам для СПб

### Что выживает

| Материал | Марка/класс | Почему |
|----------|------------|--------|
| Тротуарная плитка | Вибропресс F200+ (200 циклов) | Выдерживает 50-70 циклов/год с запасом |
| Бетон | B25 F150+ W6 | Морозостойкость + водонепроницаемость |
| Щебень в основание | Гранит фр. 20-40, 5-20 | Не размокает, морозостойкий |
| Песок | Крупный мытый, Мкр >= 2.5 | Не пучинится, хорошо дренирует |
| Геотекстиль | Дорнит 200-300 г/м2 | Разделение слоёв, фильтрация |
| Дренажная труба | ПНД с геотекстильной обмоткой | Не заиливается |
| Древесина (контакт с грунтом) | Лиственница, дуб | Естественная стойкость к гниению |
| Крепёж | Нержавейка A2/A4 или горячий цинк | Обычный ржавеет за 2-3 года |

### Что НЕ выживает

| Материал | Проблема | Срок до разрушения |
|----------|----------|--------------------|
| Плитка вибролитая F50 | 50 циклов = 1 сезон в СПб | 1-3 года |
| Бетон M150 без F | Крошится после первой зимы | 2-4 года |
| Известняковый щебень | Размокает, теряет прочность | 3-5 лет |
| Песок пылеватый Мкр < 1.5 | Пучинится, не дренирует | Сразу проблемы |
| Сосна без обработки | Гниение, синева, жуки | 3-7 лет |
| Обычный крепёж (чёрный) | Коррозия во влажном климате | 1-3 года |
| Силикатный кирпич (подпорные) | Впитывает воду, крошится | 5-10 лет |
