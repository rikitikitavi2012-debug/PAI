# LS Drainage --- Дренаж и ливневая канализация

> Проектирование и монтаж дренажных систем и ливневой канализации для загородных участков СПб/ЛО.
> Источники: СП 250.1325800.2016, СП 32.13330.2018, СП 131.13330.2018, ГОСТ 8411-74, практический опыт СПб/ЛО.

---

## 1. Типы дренажных систем

| Тип | Когда применяется | Глубина заложения | Стоимость (₽/п.м.) | Срок службы |
|-----|-------------------|-------------------|---------------------|-------------|
| **Поверхностный** (лотки, канавы) | Отвод дождевой воды с площадок и дорожек | 0-0.3 м | 800-1 500 | 20-30 лет |
| **Глубинный трубчатый** | Понижение УГВ, защита фундамента | 0.8-1.5 м | 1 200-2 500 | 30-50 лет |
| **Пристенный** | Защита подвалов и цокольных этажей | На уровне фундамента | 2 000-3 500 | 30-50 лет |
| **Пластовый** | Под фундаментной плитой на глинах/торфах | Под плитой (0.3-0.5 м щебня) | 3 000-5 000 | 50+ лет |

### Выбор типа --- алгоритм

```
УГВ < 1.0 м?
  ├── ДА → Глубинный дренаж ОБЯЗАТЕЛЬНО
  │         ├── Есть подвал? → Пристенный + кольцевой
  │         └── Нет подвала? → Кольцевой по периметру
  └── НЕТ → Достаточно ливневой канализации
             ├── Глина/суглинок? → Добавить точечный дренаж в низинах
             └── Песок? → Только ливнёвка
```

## 2. Расчёт дренажа

### 2.1 Определение объёма стока

**Формула рационального метода (СП 32.13330):**

```
Q = q × F × ψ

Где:
  Q   --- расчётный расход стока (л/с)
  q   --- интенсивность дождя (л/с на га)
  F   --- площадь водосбора (га)
  ψ   --- коэффициент стока (безразмерный)
```

**Интенсивность дождя для СПб** (СП 131.13330, повторяемость 1 раз/год):

```
q₂₀ = 80 л/с·га  (длительность 20 мин)
q₅  = 120 л/с·га  (длительность 5 мин --- пиковый)
```

### 2.2 Коэффициенты стока (ψ)

| Тип поверхности | ψ | Примечание |
|-----------------|---|-----------|
| Кровля (металл, черепица) | 0.95 | Почти весь объём уходит в водосток |
| Бетон, асфальт | 0.85 | Микротрещины поглощают ~15% |
| Тротуарная плитка с швами | 0.60 | Швы пропускают воду в основание |
| Щебёночное покрытие | 0.40 | Значительная инфильтрация |
| Грунт (утрамбованный) | 0.30 | Зависит от типа грунта |
| Газон на суглинке | 0.15 | Трава + корни задерживают воду |
| Газон на песке | 0.10 | Максимальное впитывание |

### 2.3 Пример расчёта (типичный участок СПб)

```
Исходные данные:
  Участок 10 соток = 0.10 га
  Кровля дома: 120 м² = 0.012 га (ψ = 0.95)
  Мощение:      80 м² = 0.008 га (ψ = 0.60)
  Газон:        600 м² = 0.060 га (ψ = 0.15)
  Грунт:        200 м² = 0.020 га (ψ = 0.30)

Расчёт (q₂₀ = 80 л/с·га):
  Q = 80 × (0.012×0.95 + 0.008×0.60 + 0.060×0.15 + 0.020×0.30)
  Q = 80 × (0.0114 + 0.0048 + 0.0090 + 0.0060)
  Q = 80 × 0.0312 = 2.50 л/с

Итого: система должна пропускать минимум 2.5 л/с
```

### 2.4 Подбор диаметра труб

| Диаметр (мм) | Пропускная способность (л/с) | Мин. уклон | Макс. длина без колодца |
|---------------|------------------------------|------------|------------------------|
| D110 | до 3.8 | 0.007 (7 мм/м) | 50 м |
| D160 | до 8.0 | 0.005 (5 мм/м) | 50 м |
| D200 | до 15.0 | 0.004 (4 мм/м) | 50 м |
| D250 | до 25.0 | 0.003 (3 мм/м) | 75 м |
| D315 | до 45.0 | 0.002 (2 мм/м) | 75 м |

> **Для участка из примера (2.5 л/с):** D110 достаточно с запасом. При объединении двух веток --- D160.

## 3. Устройство глубинного дренажа

### 3.1 Поперечное сечение траншеи

```
                    ← 400-600 мм →
    ┌─────────────────────────────────┐
    │         Плодородный грунт       │  50-100 мм
    ├─────────────────────────────────┤
    │         Песок (крупный)         │  100-150 мм
    ├═════════════════════════════════┤
    │ ┌─────────────────────────────┐ │
    │ │     Геотекстиль (обёртка)   │ │
    │ │  ┌───────────────────────┐  │ │
    │ │  │ Щебень гр. 20-40 мм  │  │ │  200-300 мм
    │ │  │    ┌─────────────┐    │  │ │
    │ │  │    │  Труба D110  │    │  │ │  ← перфорированная
    │ │  │    │  в геоткани   │    │  │ │     с фильтром
    │ │  │    └─────────────┘    │  │ │
    │ │  │ Щебень гр. 20-40 мм  │  │ │  100 мм (подсыпка)
    │ │  └───────────────────────┘  │ │
    │ └─────────────────────────────┘ │
    └─────────────────────────────────┘

    Общая глубина траншеи: 800-1200 мм
    Ширина траншеи: 400-600 мм
```

### 3.2 Послойная спецификация

| Слой (снизу вверх) | Материал | Толщина | Назначение |
|---------------------|----------|---------|-----------|
| 1. Геотекстиль (дно+стенки) | Дорнит 150-200 г/м² | --- | Защита от заиливания |
| 2. Подсыпка | Щебень гранитный 20-40 мм | 100 мм | Ложе для трубы |
| 3. Дренажная труба | ПНД D110 перфорированная в геоткани | --- | Сбор и отвод воды |
| 4. Обсыпка | Щебень гранитный 20-40 мм | 200-300 мм | Фильтрация и водоприём |
| 5. Геотекстиль (завёрнутый) | Дорнит 150-200 г/м² | --- | Закрытие фильтрующего пакета |
| 6. Песок крупный | Фракция 2-5 мм | 100-150 мм | Буферный слой |
| 7. Плодородный грунт | Обратная засыпка | 50-100 мм | Восстановление поверхности |

### 3.3 Спецификации труб

| Параметр | Требование |
|----------|-----------|
| Материал | ПНД (полиэтилен низкого давления) или ПВХ |
| Перфорация | 2/3 окружности, отверстия 1.5-5 мм |
| Жёсткость кольцевая | SN4 (глубина до 2 м) / SN8 (до 4 м) |
| Фильтрующая обмотка | Геотекстиль плотностью 100-150 г/м² |
| Уклон | 0.003-0.005 (3-5 мм/м) |
| Минимальный уклон (допустимо) | 0.002 (2 мм/м) |

## 5. Грунты и УГВ СПб/ЛО

### 5.1 Типы грунтов и водопроницаемость

| Грунт | Коэф. фильтрации k (м/сут) | Типичный УГВ (м) | Необходимость дренажа | Распространение в ЛО |
|-------|-----------------------------|-------------------|-----------------------|-----------------------|
| Глина | 0.001-0.01 | 0.3-0.8 | **Обязательно** | Очень часто (40%) |
| Суглинок тяжёлый | 0.01-0.1 | 0.5-1.0 | **Обязательно** | Часто (25%) |
| Суглинок лёгкий | 0.1-0.5 | 0.8-1.5 | Рекомендуется | Часто (15%) |
| Песок мелкий | 1.0-5.0 | 1.0-2.0 | Только ливнёвка | Карельский перешеек |
| Песок крупный | 5.0-20.0 | 1.5-3.0 | Не нужен | Редко (5%) |
| Торф | 0.01-1.0* | 0.0-0.5 | **Обязательно** + замена | Низины, бывшие болота |

> \* Торф: коэффициент фильтрации обманчив --- вода застаивается из-за капиллярного эффекта.

### 5.2 Специфика СПб/ЛО

```
Ключевые факторы:
1. Высокий УГВ: 0.5-1.0 м в низинных районах (Всеволожский, Ломоносовский)
2. Глинистые грунты доминируют: 65% территории ЛО --- глины и суглинки
3. Сезонное поднятие УГВ: весна (снеготаяние) + осень (затяжные дожди)
4. Морозное пучение: глины и суглинки при замерзании расширяются на 5-9%
5. Годовые осадки: 650-700 мм (СПб), ~60% в виде дождя
6. Заморозки: с октября по апрель --- 180+ дней ниже нуля
```

### 5.3 Районы повышенного риска (ЛО)

| Район | Проблема | Рекомендация |
|-------|---------|--------------|
| Всеволожский (низины) | УГВ 0.3-0.5 м, торфяники | Пластовый + кольцевой дренаж |
| Приозерский | Скальные выходы + глина | Поверхностный дренаж + канавы |
| Ломоносовский | Тяжёлые глины | Глубинный дренаж обязателен |
| Курортный (Сестрорецк) | Песок, высокий УГВ у залива | Ливнёвка + отсыпка участка |
| Гатчинский | Суглинки, пологий рельеф | Комбинированный дренаж |

## 8. Типичные ошибки

### Flaw ID: LS_DRAIN_NO_SLOPE
**Описание:** Дренажная труба уложена без уклона или с контруклоном.
**Последствия:** Вода стоит в трубе, заиливание за 2-3 сезона, полная потеря функции.
**Как правильно:** Минимальный уклон 0.003 (3 мм/м). Контроль нивелиром при укладке.

### Flaw ID: LS_DRAIN_NO_GEOTEXTILE
**Описание:** Дренажная труба обсыпана щебнем без геотекстиля.
**Последствия:** Глинистые частицы забивают щебень и перфорацию за 3-5 лет.
**Как правильно:** Геотекстиль Дорнит 150+ г/м² оборачивает ВЕСЬ щебёночный пакет.

### Flaw ID: LS_DRAIN_MIXED_SYSTEMS
**Описание:** Дренаж и ливнёвка объединены в одну трубу.
**Последствия:** При ливне дренажная система захлёбывается, вода идёт обратно в грунт.
**Как правильно:** ДВЕ раздельных системы. Объединение только в точке сброса (конечный колодец).

### Flaw ID: LS_DRAIN_SHALLOW_FOUNDATION
**Описание:** Дренаж заложен выше подошвы фундамента.
**Последствия:** Вода подмывает фундамент снизу. Трещины, просадка.
**Как правильно:** Дренажная труба минимум на 0.5 м ниже низа фундамента.

### Flaw ID: LS_DRAIN_NO_INSPECTION
**Описание:** Нет смотровых колодцев на поворотах.
**Последствия:** Невозможность прочистки. Засор = демонтаж и переукладка.
**Как правильно:** Колодец D315 на каждом повороте и каждые 50 м прямого участка.

### Flaw ID: LS_DRAIN_WRONG_GRAVEL
**Описание:** Использован известняковый щебень вместо гранитного.
**Последствия:** Известняк размывается кислыми грунтовыми водами (pH 5-6 в торфяных грунтах ЛО). Через 5-7 лет щебень превращается в кашу, фильтрация падает в 10 раз.
**Как правильно:** Только гранитный щебень фракции 20-40 мм. Известняк --- категорически нет.
