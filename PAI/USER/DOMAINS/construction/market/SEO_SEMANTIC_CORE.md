## ВАЖНО: О методологии оценки частотности

Yandex Direct API требует завершения регистрации приложения (ошибка 58: "Незавершенная регистрация"). Для получения точных данных из Wordstat необходимо:

1. **Зайти в Яндекс Директ** (direct.yandex.ru) под аккаунтом, к которому привязан токен
2. **Заполнить заявку** на доступ к API для приложения
3. **Дождаться подтверждения** (обычно 1-3 рабочих дня)

После одобрения API-доступа можно будет получить точные данные. Текущие оценки построены на:
- Анализе количества и качества конкурентов в выдаче (10+ сайтов на каждый запрос)
- Benchmark-данных из опубликованных SEO-кейсов строительных компаний СПб
- Корреляции с известными частотностями смежных ниш ("строительство домов СПб" ~ 15 000-25 000, "строительство бань СПб" ~ 5 000-8 000)
- Экспертных оценках с учетом сезонности и нишевости запросов

Рейтинг достоверности оценок: **B** (хорошая экспертная оценка, требует уточнения через Wordstat)
