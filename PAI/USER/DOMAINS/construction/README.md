## Как использовать

- При расчете сметы: читать шаблон из `templates/` + нормативы из `normatives/`
- При работе с клиентом: следовать процессу из `processes/Lead_to_Cash.md`
- При проверке на соответствие: использовать чек-листы из `normatives/`
- Для будущего Construction Orchestrator: `reference/Agent_Architecture.md`
