# Термины: Веранда и Терраса — выжимка по СП 54.13330.2016

## TL;DR чек-лист (для быстрого применения)
- **Терраса**: Открытая площадка, может иметь крышу, но не имеет стен (или стены не более чем с двух сторон). Площадь считается с коэффициентом **0.3** [Приложение Б].
- **Веранда**: Застеклённое, неотапливаемое помещение, пристроенное к дому или встроенное в него. Считается частью дома. Площадь считается с коэффициентом **1.0** [Приложение Б].
- **Балкон**: Выступает из плоскости стены фасада, имеет ограждение.
- **Лоджия**: Встроена в здание, имеет стены с трёх сторон.
- **Ключевое отличие**: Если помещение застеклено со всех сторон — это веранда. Если оно открытое (даже с крышей) — это терраса.

## Область применения
- Свод правил устанавливает нормы для проектирования многоквартирных жилых зданий, однако **Приложение Б** к этому документу содержит общепринятые в строительной и юридической практике определения летних помещений, которые используются для классификации объектов ИЖС [п. 1.1].

## Ключевые определения
- **Терраса** — ограждённая открытая площадка, пристроенная к зданию или размещённая на кровле нижерасположенного этажа. Может иметь крышу [п. Б.24, Приложение Б].
- **Веранда** — застеклённое неотапливаемое помещение, пристроенное к зданию или встроенное в него, не имеющее ограничения по глубине [п. Б.8, Приложение Б].
- **Балкон** — вынесенная из плоскости стены фасада ограждённая площадка. Может быть остеклён [п. Б.4, Приложение Б].
- **Лоджия** — встроенное в здание или пристроенное к нему, открытое во внешнее пространство, ограждённое с трёх сторон стенами помещение. Может быть остеклена [п. Б.14, Приложение Б].

## Пошаговое применение для классификации объекта
1.  **Оценить наличие остекления**: Если помещение полностью застеклено по периметру, это веранда.
2.  **Оценить открытость**: Если помещение открыто с одной или нескольких сторон (даже при наличии крыши и ограждений), это терраса.
3.  **Применить коэффициент**: При расчёте общей площади дома для технических или коммерческих целей использовать соответствующий коэффициент (0.3 для террасы, 1.0 для веранды).

## Типовые ошибки и как избежать
- **Ошибка**: Называть застеклённую пристройку "террасой". Это юридически неверно и может привести к путанице в документах БТИ и при налогообложении.
  - **Как правильно**: Всегда использовать термин "веранда" для полностью застеклённых неотапливаемых пристроек.
- **Ошибка**: Применение неправильного коэффициента при расчёте площади. Например, учёт площади террасы с коэффициентом 1.0.
  - **Как правильно**: Строго следовать коэффициентам из Приложения А: 0.3 для террас и балконов, 0.5 для лоджий, 1.0 для веранд.
