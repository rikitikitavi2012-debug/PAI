# Тепловая защита зданий — выжимка по СП 50.13330.2012

## TL;DR чек-лист (для быстрого применения)
- **Определить ГСОП**: Найти градусо-сутки отопительного периода (ГСОП, °С·сут) для города строительства. Эти данные есть в `SP131_Climatology.md` (на основе СП 131.13330).
- **Найти требуемое R_req**: По таблице 3 найти нормируемое сопротивление теплопередаче `R_req` для стен, покрытий и **окон**, соответствующее вашему ГСОП.
- **Сравнить с проектом**: Убедиться, что `R_o` (приведенное сопротивление теплопередаче) стены/покрытия/окна в проекте **больше или равно** `R_req`.
- **Проверить окна**: Для отапливаемой веранды `R_o` оконного блока должно быть не меньше значения из таблицы 3 для окон (например, для Москвы с ГСОП ~5000, `R_req` для окон ≈ 0,54 м²·°С/Вт).
- **Исключить мостики холода**: Проверить узлы примыкания конструкций. Металлические связи, бетонные перемычки без утепления — это «мостики холода», которые нужно минимизировать.

## Область применения
- Свод правил устанавливает требования к тепловой защите ограждающих конструкций (стен, крыш, окон) зданий и сооружений для обеспечения комфортных условий внутри и снижения расхода энергии на отопление [п. 1.1].

## Ключевые определения
- **Приведенное сопротивление теплопередаче (R_o, м²·°С/Вт)**: Основной показатель теплозащитных свойств ограждающей конструкции в целом, учитывающий неоднородности (швы, стыки, крепёж) [п. 3.14].
- **Градусо-сутки отопительного периода (ГСОП, °С·сут)**: Интегральный показатель суровости климата, равный произведению разности средней температуры внутри и снаружи на длительность отопительного периода. **Чем выше ГСОП, тем теплее должны быть стены и окна** [п. 3.6].
- **Мостик холода (теплопроводное включение)**: Элемент конструкции (металл, бетон) с высокой теплопроводностью, через который происходят повышенные теплопотери.

## Таблицы норм и минимальные требования
- **Таблица 3. Нормируемые значения сопротивления теплопередаче ограждающих конструкций `R_req`**:
  - Это **ключевая таблица** документа. В ней по значению ГСОП для вашего города определяются минимально допустимые `R_req` для:
    - Стен
    - Покрытий (крыш)
    - Окон и балконных дверей
    - Перекрытий над проездами и подвалами
- **Пример для г. Москва (ГСОП ≈ 5000 °С·сут)**:
  - `R_req` для стен: **3,13 м²·°С/Вт**
  - `R_req` для покрытий: **4,69 м²·°С/Вт**
  - `R_req` для окон: **0,54 м²·°С/Вт**

## Пошаговое применение для «тёплой» веранды
1.  **Найти ГСОП**: Определить ГСОП для региона строительства (см. `SP131_Climatology.md`).
2.  **Определить R_req**: По таблице 3 найти требуемые `R_req` для стен, кровли и окон веранды.
3.  **Рассчитать R_o стены**: Рассчитать фактическое сопротивление теплопередаче стены веранды по формуле: `R_o = Σ (δ_i / λ_i)`, где `δ` — толщина слоя материала (например, утеплителя), а `λ` — его коэффициент теплопроводности. Убедиться, что `R_o ≥ R_req`.
4.  **Подобрать остекление**: Выбрать оконные блоки, у которых паспортное значение `R_o` (предоставляется производителем) не ниже, чем `R_req` для окон из таблицы 3.
5.  **Проверить на выпадение конденсата**: Убедиться, что температура на внутренней поверхности ограждающих конструкций (особенно в углах и у окон) не опускается ниже точки росы [п. 5.10].

## Типовые ошибки и как избежать
- **Ошибка**: Неправильное определение ГСОП, что ведёт к неверному выбору `R_req` и, как следствие, к холодному или слишком дорогому дому.
  - **Как правильно**: Всегда использовать актуальные данные из СП 131 «Строительная климатология».
- **Ошибка**: Расчёт теплозащиты стены «по слоям» без учёта мостиков холода (крепежа, профилей каркаса).
  - **Как правильно**: Использовать коэффициент теплотехнической однородности `r`, который снижает расчётное `R_o`. Для каркасных стен он может составлять 0,7-0,8.
- **Ошибка**: Выбор мощного утеплителя для стен и экономия на окнах. Через плохие окна может уходить до 40% тепла.
  - **Как правильно**: Подходить к утеплению комплексно. `R_req` для окон так же важен, как и для стен.
