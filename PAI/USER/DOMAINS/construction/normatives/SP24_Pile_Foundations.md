# SP24_Pile_Foundations

**Version:** 1.0
**Last Updated:** 2025-11-03

## 1. Key Excerpts

Данный Свод правил устанавливает требования к проектированию и расчету свайных фундаментов, в том числе для зданий и сооружений, возводимых на слабых и пучинистых грунтах.

-   **Классификация:** Сваи классифицируются по способу заглубления в грунт (забивные, винтовые, буровые), по характеру взаимодействия с грунтом (сваи-стойки, висячие сваи).
-   **Несущая способность:** Несущая способность сваи (Fd) определяется как наименьшее из двух значений: несущей способности по материалу сваи и несущей способности по грунту основания.
-   **Требования к винтовым сваям:** Регламентируются минимальная толщина стенки ствола и лопасти, а также обязательные требования к антикоррозионному покрытию (горячее цинкование или двухкомпонентные эпоксидные составы).
-   **Морозное пучение:** Глубина заложения свайного фундамента должна быть ниже расчетной глубины промерзания грунта для исключения воздействия сил морозного пучения.

## 2. Area of Application

Является основным расчетным документом для проектирования фундаментов на винтовых сваях для всех объектов (беседки, террасы, навесы, легкие пристройки).

## 5. Calculation Algorithms (Pseudo-code)

**Алгоритм 12: Расчет несущей способности винтовой сваи**
1.  **INPUT:** `pile_type` (e.g., СВС-108), `soil_type` (из `SP22_Foundations.md`), `load_per_pile (N)`.
2.  `// Получаем табличные данные по свае и грунту`
3.  `bearing_capacity_soil = GET_SOIL_BEARING_CAPACITY('Table 14', pile_type, soil_type)`
4.  `bearing_capacity_material = GET_MATERIAL_BEARING_CAPACITY(pile_type)` // Расчет по прочности стали
5.  `// Несущая способность сваи - минимальное из двух значений`
6.  `Fd = MIN(bearing_capacity_soil, bearing_capacity_material)`
7.  `// Проверка условия прочности`
8.  `IF N <= Fd THEN RETURN 'PASS'`
9.  `ELSE RETURN 'FAIL: Load exceeds pile capacity. Required: ' + N + ', Available: ' + Fd`

| Параметр | Требование | Примечание |
|---|---|---|

## 8. Typical Design Flaws (for AI detection)

1.  **`Flaw ID: INSUFFICIENT_DEPTH`**: Проект террасы в Ленинградской области (глубина промерзания 1.44 м) с глубиной заложения винтовых свай 1.2 м. **Риск:** Силы морозного пучения "выдавят" сваи в первую же зиму, что приведет к необратимой деформации всей конструкции.
2.  **`Flaw ID: CORROSION_VULNERABLE`**: В спецификации к проекту указаны "Сваи винтовые СВС-108" без спецификации типа антикоррозионного покрытия. **Риск:** Подрядчик может использовать самые дешевые сваи, покрытые только грунтом, которые проржавеют в агрессивном грунте за 5-7 лет, приведя к аварийному состоянию.
3.  **`Flaw ID: OVERLOAD`**: Нагрузка на одну сваю от каркаса навеса составляет 4.2 тонны, в то время как ее несущая способность по грунту (суглинок) составляет 3.5 тонны. **Риск:** Просадка фундамента, деформация или обрушение конструкции.
