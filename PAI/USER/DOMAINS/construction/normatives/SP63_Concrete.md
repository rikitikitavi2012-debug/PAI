## TL;DR (Краткая выжимка)
- Выбрать класс бетона по прочности (например, B25) и класс арматуры (например, A500С) в зависимости от нагрузок и условий эксплуатации [п. 6.1, 6.2].
- Обеспечить минимальный защитный слой бетона для арматуры (для фундаментов в грунте — не менее 40-70 мм) для защиты от коррозии [п. 10.3.1, табл. 10.1].
- Рассчитать сечение и армирование элемента на прочность по первой группе предельных состояний (чтобы не сломался) [раздел 8].
- Проверить элемент по второй группе предельных состояний — на трещиностойкость и прогибы (чтобы не прогнулся и не потрескался сверх нормы) [раздел 8].
- Особое внимание уделить правильному армированию узлов: анкеровке стержней, поперечному армированию колонн и зон продавливания плит [п. 10.3].

### Область применения
- Свод правил устанавливает требования к проектированию бетонных и железобетонных конструкций из тяжелого, мелкозернистого и лёгкого бетонов без предварительного напряжения арматуры [п. 1.1].
- Применяется при проектировании зданий и сооружений различного назначения.

### Ключевые определения
- **Тяжелый бетон**: Основной вид бетона для несущих конструкций с плотностью от 2200 до 2500 кг/м³ [п. 3.4].
- **Класс бетона по прочности на сжатие (B)**: Главная прочностная характеристика бетона. Например, класс B25 означает, что бетон гарантированно выдерживает давление 25 МПа [п. 6.1.2].
- **Арматура (класса A/B)**: Стальные стержни, предназначенные для восприятия растягивающих (иногда сжимающих) усилий в железобетоне. Например, A500С — наиболее распространённый класс [п. 6.2.1].
- **Защитный слой бетона**: Расстояние от грани элемента до поверхности ближайшего арматурного стержня. Его основная функция — защита арматуры от коррозии [п. 10.3.1].

### Таблицы норм и минимальные требования
- **Таблица 6.1**: Расчётные сопротивления бетона на сжатие (`R_b`) и растяжение (`R_bt`) для разных классов [табл. 6.1].
- **Таблица 6.7**: Расчётные сопротивления арматуры на растяжение (`R_s`) для разных классов [табл. 6.7].
- **Таблица 10.1**: Минимальная толщина защитного слоя бетона. Для фундаментов в грунте при наличии подготовки — 40 мм, без подготовки — 70 мм. Для наружных конструкций (колонны, балки) — 25-30 мм [табл. 10.1].
- **Пункт 10.3.5**: Минимальные проценты армирования для различных элементов (например, для сжатых элементов, таких как стойки, — не менее 0,25%) [п. 10.3.5].

### Пошаговое применение для террас/веранд/навесов
1.  **Выбрать материалы**: Определить класс бетона (для столбчатых фундаментов обычно B20-B25) и класс арматуры (A500С).
2.  **Определить нагрузки**: Собрать нагрузки на фундамент (опорный столб) от вышележащих конструкций (вес каркаса, кровли, снега) из расчётов по СП 20, СП 64 или СП 16.
3.  **Рассчитать столбчатый фундамент (стойку)**:
    - По нагрузке `N` от колонны каркаса рассчитать сечение стойки на центральное или внецентренное сжатие по формулам из раздела 8.1.
    - Определить требуемую площадь продольной арматуры `A_s`.
    - Назначить конструктивно поперечную арматуру (хомуты) для предотвращения выпучивания продольных стержней [п. 10.3.11].
4.  **Проверить защитный слой**: Убедиться, что толщина защитного слоя бетона соответствует требованиям таблицы 10.1 для условий эксплуатации (например, для фундамента в грунте).

### Формулы и коэффициенты (если применимо)
- **Расчет на прочность внецентренно сжатого элемента (общий принцип)**: Прочность считается обеспеченной, если внешние усилия (момент `M` и сила `N`) не превышают предельных усилий, которые может воспринять сечение [п. 8.1.20].
- **Коэффициенты условий работы бетона `γ_bi`**: Учитывают длительность действия нагрузки, условия твердения и другие факторы. Для большинства стандартных случаев принимаются равными 1,0 [п. 6.1.12].
- **Минимальный процент армирования `μ_s,min`**: Важный параметр, предотвращающий хрупкое разрушение элемента. Например, для изгибаемых элементов `μ_s,min` определяется по формуле (10.9) [п. 10.3.5].

### Типовые ошибки и как избежать
- **Ошибка**: Недостаточный защитный слой бетона в фундаментах. Это самая частая причина разрушения опорных столбов из-за коррозии арматуры.
  - **Как правильно**: Строго соблюдать требования таблицы 10.1 (40/70 мм для фундаментов).
- **Ошибка**: Неправильная анкеровка (заделка) арматурных выпусков из фундамента для крепления стальной или деревянной колонны.
  - **Как правильно**: Длина анкеровки должна быть достаточной для передачи усилия с арматуры на бетон, рассчитывается по разделу 10.3.
- **Ошибка**: Отсутствие или недостаточный шаг поперечной арматуры (хомутов) в сжатых стойках.
  - **Как правильно**: Устанавливать хомуты с шагом, не превышающим нормативных значений (например, не более 15`d` продольной арматуры) для предотвращения их выпучивания [п. 10.3.11].

## 1. Key Excerpts

Данный Свод правил устанавливает требования к расчету и проектированию бетонных и железобетонных конструкций, изготавливаемых из тяжелого, мелкозернистого, легкого и ячеистого бетонов.

-   **Предельные состояния:** Расчет производится по двум группам предельных состояний: первая группа (по несущей способности) и вторая группа (по пригодности к нормальной эксплуатации, т.е. по трещиностойкости и деформациям).
-   **Материалы:** Вводятся классы бетона по прочности на сжатие (B), классы арматуры по прочности на растяжение (A) и их расчетные сопротивления (Rb и Rs).
-   **Конструктивные требования:** Регламентируются минимальные размеры сечений, толщина защитного слоя бетона, правила расположения и анкеровки арматуры.
-   **Долговечность:** Для обеспечения долговечности конструкции необходимо учитывать условия эксплуатации, агрессивность среды и назначать соответствующие марки бетона по водонепроницаемости (W) и морозостойкости (F).

## 2. Area of Application

## 5. Calculation Algorithms (Pseudo-code)

**Алгоритм 10: Расчет армирования прямоугольного сечения при изгибе**
1.  **INPUT:** `Moment (M)`, `width (b)`, `height (h)`, `concrete_class`, `reinforcement_class`.
2.  `Rb = GET_CONCRETE_STRENGTH(concrete_class)` (из Таблицы 13)
3.  `Rs = GET_REINFORCEMENT_STRENGTH(reinforcement_class)` (из Таблицы 12)
4.  `protective_layer = GET_PROTECTIVE_LAYER('foundation_in_ground')` // e.g., 40 mm
5.  `h0 = h - protective_layer` // Рабочая высота сечения
6.  `alpha_m = M / (b * h0^2 * Rb)`
7.  `IF alpha_m > alpha_R THEN RETURN 'FAIL: Section size is not enough!'`
8.  `zeta = 0.5 * (1 + sqrt(1 - 2 * alpha_m))`
9.  `// Расчет требуемой площади арматуры`
10. `As_required = M / (Rs * zeta * h0)`
11. `RETURN As_required`

## 8. Typical Design Flaws (for AI detection)

1.  **`Flaw ID: INSUFFICIENT_PROTECTIVE_LAYER`**: В проекте ленточного фундамента, контактирующего с грунтом, указан защитный слой бетона для рабочей арматуры 25 мм. **Риск:** Прямое нарушение СП 63 (требуется не менее 40 мм). Арматура начнет корродировать в первые 3-5 лет, что приведет к трещинам и разрушению фундамента.
2.  **`Flaw ID: WRONG_CONCRETE_CLASS`**: Для плитного фундамента под двухэтажную пристройку заложен бетон класса В15 (М200). **Риск:** Недостаточная прочность бетона. Под нагрузкой в бетоне могут возникнуть необратимые деформации. Современные нормы требуют для фундаментов класс не ниже В22.5.
3.  **`Flaw ID: INCORRECT_ANCHORAGE`**: Недостаточная длина анкеровки рабочей арматуры балки в месте ее опоры на стену. **Риск:** "Проскальзывание" арматуры в бетоне под нагрузкой, что равносильно ее отсутствию. Узел не будет работать так, как заложено в расчете.
