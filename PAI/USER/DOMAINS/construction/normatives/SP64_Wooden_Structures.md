## TL;DR (Краткая выжимка)
- **Выбрать сорт древесины**: Для несущих конструкций террас (лаги, стойки, стропила) использовать древесину (сосна, ель) **не ниже 2-го сорта** [п. 6.3].
- **Проверить влажность**: Влажность древесины для наружных конструкций не должна превышать **20%** [п. 6.7.4].
- **Подобрать сечение**: Рассчитать элементы на прочность и прогиб, используя расчётные сопротивления из таблицы ниже.
- **Проверить прогибы**: Относительный прогиб для балок перекрытия (лаг) не должен превышать `l/250` [табл. Л.1].
- **Обеспечить защиту**: Все элементы, особенно в местах контакта с бетоном или грунтом, должны быть антисептированы [раздел 10].

### Мини-формуляр для расчёта
- **Проверка прочности на изгиб**:
  `M / W_net ≤ R_и * m_дл`
  - `M` — максимальный изгибающий момент от нагрузки (из `SP20_Loads_and_Impacts.md`).
  - `W_net` — момент сопротивления сечения нетто.
  - `R_и` — расчётное сопротивление изгибу (из таблицы ниже).
  - `m_дл` — коэффициент, учитывающий длительность действия нагрузки (для снега ≈ 0,8).
- **Проверка на прогиб**:
  `f / l ≤ [u]`
  - `f` — фактический прогиб от нормативной нагрузки.
  - `l` — пролёт балки.
  - `[u]` — предельный относительный прогиб (обычно `1/250`).

### Таблицы норм (для несущих элементов террас)
**Таблица. Расчётные сопротивления древесины (сосна, ель) 2-го сорта, МПа** [на основе табл. Е.1]

| Вид сопротивления | Расчётное сопротивление, R |
| :---------------- | :------------------------- |
| Изгиб (`R_и`) | 14 |
| Сжатие вдоль волокон (`R_с`) | 13 |
| Смятие поперёк волокон (`R_см90`) | 1,8 |
| Срез вдоль волокон (`R_ск`) | 1,2 |

### Пошаговое применение для лаги террасы
1.  **Исходные данные**: Лага из доски 50x200 мм (сосна, 2 сорт), пролёт `l`=3 м, нагрузка от снега `q`=2,5 кН/м.
2.  **Проверка прочности**:
    - Момент `M = q*l²/8` = 2,5 * 3² / 8 = 2,81 кН·м.
    - Момент сопротивления `W = b*h²/6` = 5*20²/6 = 333,3 см³.
    - Напряжение `σ = M/W` = 2,81*10⁵ / 333,3 ≈ 8,4 МПа.
    - `R_и * m_дл` = 14 * 0,8 = 11,2 МПа.
    - **Вывод**: 8,4 МПа < 11,2 МПа. **Прочность обеспечена.**
3.  **Проверка прогиба**: Расчёт показывает, что прогиб будет в пределах нормы `l/250`.

### Типовые ошибки и как избежать
- **Ошибка**: Использование древесины 3-го сорта или «ТУ» для несущих конструкций. Это недопустимо и опасно.
  - **Как правильно**: Требовать у поставщика сертификат, подтверждающий сорт древесины не ниже 2-го по ГОСТ 8486.
- **Ошибка**: Неправильный учёт длительности нагрузки, что завышает несущую способность.
  - **Как правильно**: Всегда применять понижающий коэффициент `m_дл` для постоянных и длительных нагрузок (снег, собственный вес).

## 1. Key Excerpts

Данный Свод правил распространяется на проектирование деревянных конструкций зданий и сооружений различного назначения.

-   **Материалы:** Для несущих конструкций следует применять древесину преимущественно хвойных пород (сосна, лиственница). Древесину твердых лиственных пород (дуб, ясень) — для ответственных деталей, таких как нагели и подушки.
-   **Предельные состояния:** Расчет конструкций производится по двум группам предельных состояний: по несущей способности (прочность, устойчивость) и по деформациям (прогибы), не препятствующим нормальной эксплуатации.
-   **Долговечность:** Долговечность конструкций должна быть обеспечена конструктивными мерами (проветривание, защита от осадков) и, при необходимости, защитной обработкой (антисептирование, огнезащита).
-   **Температурно-влажностный режим:** Применение деревянных конструкций допускается при температуре окружающего воздуха не выше 50°С. Для клееной древесины температура выше 35°С допускается только при относительной влажности воздуха не менее 50%.

## 2. Area of Application

Требования СП являются обязательными при проектировании любых объектов из древесины, в особенности для объектов :

-   Террасы и веранды (расчет балок перекрытия, стоек, стропил).
-   Беседки (расчет каркаса, стропильной системы).
-   Навесы (расчет прогонов, стоек, узлов крепления).

## 5. Calculation Algorithms (Pseudo-code)

**Алгоритм 2: Расчет на смятие одного среза болтового соединения**
1.  **Определить несущую способность на смятие центрального элемента (T1):** `T1 = d * a * R_cm,a` (d - диаметр болта, a - толщина элемента, R_cm,a - расчетное сопротивление смятию).
2.  **Определить несущую способность на смятие крайних элементов (T2):** `T2 = d * (2*c) * R_cm,c` (c - толщина крайнего элемента).
3.  **Определить несущую способность на изгиб болта (T3):** `T3 = k_d * d^2 * sqrt(2*M_y*R_cm,a)` (k_d - коэффициент, M_y - момент сопротивления).
4.  **Выбрать минимальное значение:** `T_bearing = min(T1, T2, T3)`. Это и есть расчетная несущая способность соединения.

## 6. Validated Load Combination Examples

**Пример для деревянной балки перекрытия террасы (Москва):**
-   **Нагрузки:** Постоянная (G) = 0.5 кПа (собственный вес), Снеговая (S) = 1.5 кПа, Полезная (L) = 4.0 кПа (для террас).
-   **Основное сочетание (для 1-й группы ПС):** `1.1*G + 1.4*L + 1.4*0.7*S = 1.1*0.5 + 1.4*4.0 + 1.4*0.7*1.5 = 0.55 + 5.6 + 1.47 = 7.62 кПа`.

## 8. Typical Design Flaws (for AI detection)

1.  **`Flaw ID: BIO_VULNERABILITY`**: Не предусмотрена гидроизоляция между деревянной стойкой и бетонным фундаментом или не проведена антисептическая обработка нижних венцов. **Риск:** Капиллярный подсос влаги, гниение, полная потеря несущей способности за 2-3 года.
2.  **`Flaw ID: POOR_VENTILATION`**: Проектирование "глухого" примыкания деревянного настила террасы к стене дома без вентиляционного зазора. **Риск:** Скопление влаги, образование плесени и грибка, разрушение и лаг, и настила.
3.  **`Flaw ID: FIRE_HAZARD`**: Размещение деревянных элементов навеса для барбекю ближе 1 метра к источнику открытого огня (мангалу) без использования огнезащитной пропитки и теплоизоляционных экранов. **Риск:** Возгорание.

## 9. Material Specifics

**9.1. Цельная древесина (Solid Timber)**
- **Применение:** Основной материал для стоек, балок, стропил в бюджетных и стандартных проектах.
- **Расчетное сопротивление (сосна, 2 сорт, изгиб):** `R_i = 13 МПа`.
- **Ограничения:** Рекомендуемые пролеты для балок до 4-5 метров. Склонна к короблению при изменении влажности.

**9.2. Клееная древесина (Glued Laminated Timber, Glulam)**
- **Применение:** Балки больших пролетов (до 12 м и более), ответственные элементы конструкций в премиум-проектах.
- **Расчетное сопротивление (класс GL24h, изгиб):** `R_i = 24 МПа`.
- **Преимущества:** Стабильность геометрии, высокая прочность, эстетичный внешний вид.
