## TL;DR (Краткая выжимка)
- **Определить глубину промерзания `d_f`**: Найти нормативную глубину промерзания для вашего региона в `SP131_Climatology.md`.
- **Выбрать тип фундамента**:
  - **Лёгкий навес/терраса**: Столбчатый или свайно-винтовой фундамент. Подошва столбов или лопасти свай должны быть **ниже глубины промерзания `d_f`**.
  - **Тяжёлая веранда (каменная)**: Ленточный мелкозаглубленный (МЗЛФ) или плитный фундамент на утеплённом основании (УШП).
- **Проверить несущую способность грунта `R`**: Убедиться, что давление под подошвой фундамента `p` не превышает расчётного сопротивления грунта `R`. Для предварительных расчётов `R` для суглинков и глин можно принять 100-150 кПа (1-1,5 кгс/см²).
- **Защита от морозного пучения**: Для пучинистых грунтов (глины, суглинки) обязательно закладывать подошву ниже глубины промерзания или применять утепление отмостки.

### Мини-гайд: Выбор фундамента для террасы
1.  **Оценить нагрузки**: Собрать вес конструкций и снеговую нагрузку (из `SP20_Loads_and_Impacts.md`).
2.  **Оценить грунт**: Определить тип грунта (песок, глина, суглинок) и глубину промерзания `d_f` (из `SP131_Climatology.md`).
3.  **Принять решение**:
    - **Грунт непучинистый (песок)**: Можно использовать мелкозаглубленные столбчатые фундаменты (глубина 0,5-0,7 м).
    - **Грунт пучинистый (глина, суглинок)**: Обязательно! Подошва фундамента ниже `d_f`. Оптимальный вариант — винтовые сваи (ниже `d_f`) или буронабивные сваи с расширением (ТИСЭ).
4.  **Подобрать размеры**:
    - **Для столба**: Площадь `A ≥ N / R`, где `N` — нагрузка на столб, `R` — несущая способность грунта. Пример: при нагрузке 2 т (20 кН) и `R`=150 кПа, `A` ≥ 20/150 ≈ 0,13 м². Подойдёт столб 40x40 см.
    - **Для винтовой сваи**: Диаметр и количество лопастей подбираются производителем под вашу нагрузку.

### Область применения
- Свод правил устанавливает требования к проектированию оснований и фундаментов вновь строящихся и реконструируемых зданий и сооружений [п. 1.1].

### Ключевые определения
- **Основание**: Массив грунта, воспринимающий нагрузку от фундамента.
- **Фундамент**: Часть сооружения, передающая нагрузку на основание.
- **Глубина сезонного промерзания грунта `d_f`**: Глубина, до которой грунт промерзает в зимний период.
- **Силы морозного пучения**: Силы, возникающие при замерзании воды в грунте и способные «выдавливать» фундамент из земли.

## 1. Key Excerpts

Данный Свод правил устанавливает требования к проектированию оснований зданий и сооружений, в том числе и для малоэтажного строительства.

-   **Инженерные изыскания:** Проектирование оснований должно выполняться на основе результатов инженерно-геологических изысканий, определяющих характеристики грунтов на площадке строительства.
-   **Расчет по предельным состояниям:** Основания рассчитываются по двум группам предельных состояний: по несущей способности (устойчивость, прочность) и по деформациям (осадки, крены), которые могут затруднить нормальную эксплуатацию конструкций.
-   **Учет климатических факторов:** При проектировании необходимо учитывать климатические особенности района строительства, в первую очередь — глубину сезонного промерзания грунта для предотвращения сил морозного пучения.
-   **Защитные мероприятия:** Следует предусматривать мероприятия по защите оснований от подземных и поверхностных вод.

## 2. Area of Application

Требования СП являются обязательными при проектировании фундаментов для всех видов конструкций (деревянных, металлических, каменных). Для объектов (террасы, веранды, беседки, навесы, пристройки) этот документ является **ключевым** для выбора типа, расчета и конструирования фундамента.

## 5. Calculation Algorithms (Pseudo-code)

**Алгоритм 3: Расчет минимальной глубины заложения фундамента с учетом морозного пучения**
1.  **Определить регион строительства:** `region = 'Московская область'`.
2.  **Найти нормативную глубину промерзания (dfn):** `dfn = GET_FROST_DEPTH_FROM_TABLE('Московская область')` → `dfn = 1.4 м`.
3.  **Определить коэффициент теплового режима (kh):** Для неотапливаемой отдельно стоящей постройки (беседка, навес) `kh = 1.1`.
4.  **Рассчитать расчетную глубину промерзания (df):** `df = dfn * kh = 1.4 * 1.1 = 1.54 м`.
5.  **Определить минимальную глубину заложения (d_min):** Подошва фундамента должна быть **ниже** расчетной глубины промерзания. `d_min > df`. Рекомендуется `d_min = 1.6 м`.

## 6. Validated Foundation Design Examples

**Пример: Свайный фундамент для легкой деревянной террасы 4x6 м (12 свай)**
-   **Нагрузка на одну сваю (N):** `N = (Вес_конструкции + Снеговая_нагрузка + Полезная_нагрузка) / Количество_свай = (15 кН + 40 кН + 96 кН) / 12 = 12.58 кН`.
-   **Несущая способность грунта (R):** Для суглинка `R = 250 кПа`.
-   **Площадь пяты сваи (A):** Для винтовой сваи d=108 мм, лопасть d=300 мм, `A = π * (0.3/2)² = 0.07 м²`.
-   **Проверка:** `Несущая способность сваи (P) = R * A = 250 * 0.07 = 17.5 кН`.
-   **Вывод:** `P (17.5 кН) > N (12.58 кН)`. Условие выполняется, фундамент подходит.

## 8. Typical Design Flaws (for AI detection)

1.  **`Flaw ID: SOIL_MISMATCH`**: Выбор мелкозаглубленного ленточного фундамента на пучинистом глинистом грунте для отапливаемой пристройки. **Риск:** Неравномерная осадка, отрыв пристройки от основного здания, трещины в стенах.
2.  **`Flaw ID: FROST_HEAVE_IGNORANCE`**: Заложение подошвы свайного фундамента для легкой беседки на глубину 1.2 м в Московской области (при нормативной глубине промерзания 1.4 м). **Риск:** Силы морозного пучения "выдавят" сваи вверх, нарушив геометрию и целостность конструкции.
3.  **`Flaw ID: POOR_DRAINAGE`**: Отсутствие уклона грунта от стен и отмостки у фундамента пристройки. **Риск:** Застаивание дождевой и талой воды у фундамента, переувлажнение грунта, что ведет к потере его несущей способности и усиливает морозное пучение.

## 9. Foundation Selection Decision Tree

**Цель:** Помочь в выборе оптимального типа фундамента.

1.  **INPUT:** `structure_weight` (тонн), `soil_type` (из Таблицы 2), `has_slope` (boolean), `is_heated` (boolean).
2.  **RULE 1:** IF `structure_weight` < 10 AND `soil_type` IN ['Пески', 'Суглинки'] AND `has_slope` == false THEN `recommendation` = '**Винтовые сваи**' (Оптимально по цене и скорости).
3.  **RULE 2:** IF `structure_weight` > 15 OR `soil_type` == 'Глины' AND `is_heated` == true THEN `recommendation` = '**Монолитная плита**' (Надежно для сложных грунтов и тяжелых строений).
4.  **RULE 3:** IF `structure_weight` > 10 AND `soil_type` IN ['Пески', 'Суглинки'] THEN `recommendation` = '**Ленточный железобетонный фундамент**'.
5.  **RULE 4:** IF `has_slope` == true THEN `add_recommendation` = 'Требуется расчет подпорных стенок или ступенчатый фундамент'.
