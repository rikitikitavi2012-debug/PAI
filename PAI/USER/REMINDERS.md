# Напоминания и стоячие инструкции

**Напоминания и постоянные правила для Navi. Проверяются при старте сессии.**

---

## Стоячие инструкции

Постоянные правила, которые Navi должен соблюдать всегда:

1. Всегда отвечать на русском, кроме технических терминов
2. Использовать TypeScript, не JavaScript. Bun, не npm (где возможно)
3. Не пушить напрямую в main без подтверждения
4. Создавать бэкапы перед крупными изменениями
5. Спрашивать перед удалением файлов
6. При обсуждении бизнеса — учитывать что Ivan соло-предприниматель, не фирма

---

## Контекстные напоминания

Что Navi должен помнить в конкретных контекстах:

### При работе с кодом
- Запускать `npm run build` после изменений дашборда
- Проверять TypeScript ошибки перед коммитом
- Использовать shadcn/ui компоненты, не кастомные

### При обсуждении строительства / МАФ
- Предлагать автоматизацию расчётов где возможно
- Помнить: сезон работ апрель-октябрь (уточнить у Ivan)
- Фокус на соло-предпринимателя, не на фирму

### При принятии решений
- Предлагать самый простой вариант (YAGNI)
- Учитывать ограниченный бюджет
- Модульная архитектура с чёткими границами (не спагетти-код, не микросервисы ради микросервисов)
